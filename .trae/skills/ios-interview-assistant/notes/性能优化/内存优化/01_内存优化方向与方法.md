# 内存优化方向与方法

## 【概念题】
**题目：** 请列举iOS App内存优化的方向和具体方法？

**答案：**

```
┌─────────────────────────────────────────────────────┐
│  iOS内存优化核心方向                                  │
├─────────────────────────────────────────────────────┤
│  1. ARC内存管理                                       │
│     ├── 避免循环引用（weak/strong dance）             │
│     ├── 使用weak修饰delegate                         │
│     └── Block中使用__weak避免循环引用                 │
├─────────────────────────────────────────────────────┤
│  2. 图片优化                                         │
│     ├── 使用SDWebImage进行异步加载和缓存              │
│     ├── 图片压缩（UIImageJPEGRepresentation）        │
│     ├── 按需加载（缩略图、渐进式加载）                │
│     └── 使用合适的图片格式（WebP/HEIF）               │
├─────────────────────────────────────────────────────┤
│  3. 资源释放                                         │
│     ├── 在dealloc中释放资源                          │
│     ├── viewDidDisappear中清理观察者                 │
│     ├── 移除通知监听、KVO监听                        │
│     └── 释放大型对象（NSData、NSArray等）             │
├─────────────────────────────────────────────────────┤
│  4. 懒加载                                           │
│     ├── 使用懒加载延迟创建对象                        │
│     ├── 单例模式（dispatch_once）                    │
│     └── 按需初始化，不用时不占用内存                  │
├─────────────────────────────────────────────────────┤
│  5. 循环优化                                         │
│     ├── for循环中避免重复创建对象                    │
│     ├── 使用autoreleasepool包裹循环                  │
│     └── 批量操作时手动管理内存                        │
├─────────────────────────────────────────────────────┤
│  6. 缓存策略                                         │
│     ├── 合理设置缓存大小和过期时间                    │
│     ├── 清理无用缓存                                 │
│     └── 使用磁盘缓存替代内存缓存                     │
├─────────────────────────────────────────────────────┤
│  7. 工具链检测                                       │
│     ├── 使用Instruments的Leaks工具检测泄漏            │
│     ├── 使用Memory Graph检测内存占用                 │
│     └── 使用Zombie检测野指针                         │
└─────────────────────────────────────────────────────┘
```

## 【场景题】
**题目：** 在一个列表页面中，如何优化图片加载带来的内存问题？

**答案：**

```objective-c
// 方案1：使用SDWebImage的图片缓存和异步加载
[self.imageView sd_setImageWithURL:[NSURL URLWithString:@"https://example.com/image.jpg"]
                  placeholderImage:[UIImage imageNamed:@"placeholder"]];

// 方案2：图片压缩
UIImage *originalImage = [UIImage imageNamed:@"large_image"];
NSData *compressedData = UIImageJPEGRepresentation(originalImage, 0.7);
UIImage *compressedImage = [UIImage imageWithData:compressedData];

// 方案3：按需加载（只加载当前屏幕可见的图片）
- (UITableViewCell *)tableView:(UITableView *)tableView cellForRowAtIndexPath:(NSIndexPath *)indexPath {
    // 只加载可见区域的图片
    if (CGRectIntersectsRect(cell.frame, tableView.bounds)) {
        [cell.imageView sd_setImageWithURL:self.imageURLs[indexPath.row]];
    } else {
        cell.imageView.image = nil;
    }
    return cell;
}
```

## 【代码示例】
```objective-c
// for循环中避免创建临时对象
// ❌ 不好的做法
for (NSInteger i = 0; i < 1000; i++) {
    NSString *str = [NSString stringWithFormat:@"Item %ld", (long)i]; // 每次循环都创建新对象
    [array addObject:str];
}

// ✅ 好的做法
NSMutableString *str = [NSMutableString string];
for (NSInteger i = 0; i < 1000; i++) {
    [str setString:@""];
    [str appendFormat:@"Item %ld", (long)i];
    [array addObject:[str copy]];
}

// 使用autoreleasepool包裹循环
for (NSInteger i = 0; i < 10000; i++) {
    @autoreleasepool {
        // 大量临时对象操作
        NSString *temp = [NSString stringWithFormat:@"%ld", (long)i];
        // ...
    }
}
```
