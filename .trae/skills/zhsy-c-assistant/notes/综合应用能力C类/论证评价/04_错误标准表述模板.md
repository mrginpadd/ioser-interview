# 论证评价 - 16种错误标准表述模板

## 答题格式

每处错误的作答格式：
```
1. 谬误类型：XXX
分析：
(哪里错？)材料由"论据"直接推导出"论点"。
(为什么错？)说明错误原因。
```

---

## 16种错误标准表述

### 1. 偷换概念
> 偷换概念：论据中"XX"和论点中"XX"概念不同，前者指XX，后者指XX，属于偷换概念。

### 2. 绝对化表述
> 绝对化表述：论点中"XX"一词太绝对，而论据中"XX"只是"XX"的一个因素/方面/条件/类别/情况，而非绝对因素，属于绝对化表述。

### 3. 论据不充分
> 论据不充分：论据中只提到了"XX"，要让论点"XX"成立，还需补充XX方面的内容，属于论据不充分。

### 4. 诉诸权威
> 诉诸权威：论据中"XX教授/专家"在XX领域可能具有权威性，而涉及的是XX领域，在该领域该专家观点不一定正确，属于诉诸权威。

### 5. 诉诸无知
> 诉诸无知：论据中"XX"未被证明（或不能证明）并不代表实际情况如此，否定性论据无法得出肯定性结论，属于诉诸无知。

### 6. 诉诸情感
> 诉诸情感：论据中"XX"仅通过情感的偏好，而非有效的逻辑和事实得出结论，属于诉诸情感。

### 7. 诉诸众人
> 诉诸众人：论据中"XX"只是多数人的观点，没有根据事实依据来说明，观点不一定可靠，属于诉诸众人。

### 8. 预期理由
> 预期理由：论据中"XX"表示可能性/过去/现在，推不出"XX"的结论，属于预期理由。

### 9. 以偏概全
> 以偏概全：论据中"XX"是部分情况，不具代表性，不足以概括总体"XX"，属于以偏概全。

### 10. 统计学谬误
> 统计学谬误：论据"XX"在运算时未考虑实际情况，导致结论错误，属于统计学谬误。

### 11. 类比不当
> 类比不当：论据中"XX"与论点中"XX"表面相似，但本质不具有可比性，不能简单类比，属于类比不当。

### 12. 强拉因果
> 强拉因果：论据"XX"与论点"XX"没有必然因果关系，属于强拉因果。

### 13. 因果倒置
> 因果倒置：
> ① 论据中由"XX"推出"XX"，而结论因果颠倒，属于因果倒置。
> ② 论据"XX"为论点"XX"的结果，而非原因，属于因果倒置。

### 14. 因果矛盾
> 因果矛盾：论据中"XX"与论点中"XX"相互冲突，属于因果矛盾。

### 15. 非黑即白
> 非黑即白：论据中"XX"除了"XX"之外，还有"XX"其他情况，不能直接否定得出极端结论，属于非黑即白。

### 16. 形式谬误
> 形式谬误：论据"XX"不一定就推出论点"XX"，推理形式有误，否定前提条件得不到否定结论，属于形式谬误。

## 作答要点

### 核心原则
1. **先指出错误类型**：明确说明是哪种谬误
2. **引用原文**：用引号标注论据和论点中的关键词
3. **分析原因**：说明为什么属于这种谬误
4. **控制字数**：错误指出不超过50字，理由说明不超过50字

### 答题步骤
```
第1步：阅读材料，标注所有论据和论点
第2步：逐一对论据和论点进行逻辑检验
第3步：识别谬误类型
第4步：按照模板组织语言作答
```

### 常见错误识别信号词
| 谬误类型 | 信号词 |
|---------|--------|
| 绝对化表述 | 一定、必然、绝对、彻底、所有、只要...就... |
| 以偏概全 | 某企业、部分、一些、个别 |
| 非黑即白 | 不是...就是...、要么...要么... |
| 诉诸权威 | 专家、教授、权威、顶级期刊 |
| 诉诸无知 | 未被证明、没有证据、尚不清楚 |

### 评分要点
- 正确指出谬误类型（得分关键）
- 准确引用原文内容
- 理由分析简明扼要
- 语言规范，符合学术表达
