# 科技文献阅读 - 关键词提取

## 核心概念

**关键词**：能够代表文献核心内容的词汇或短语。

关键词提取是科技文献阅读的基础能力，有助于快速把握文献主旨。

## 提取方法

### 1. 高频词法
统计文献中出现频率较高的词汇

**步骤**：
1. 通读文献
2. 标记出现3次以上的词汇
3. 筛选与主题相关的高频词

### 2. 主题词法
根据文献主题确定核心词汇

**示例**：
主题：深度学习在医学影像中的应用
可能的关键词：深度学习、医学影像、卷积神经网络、图像识别、AI诊断

### 3. 标题分析法
从标题中提取核心词汇

**示例**：
标题：《基于Transformer的自然语言处理模型优化方法》
关键词：Transformer、自然语言处理、模型优化

### 4. 摘要分析法
从摘要中提取核心信息词

## 提取步骤

1. **通读全文**：了解文献整体内容
2. **标注核心内容**：主题、方法、结果、结论
3. **提取关键词**：从核心内容中筛选
4. **验证调整**：确保关键词覆盖主要内容

## 常见关键词类型

### 1. 研究对象
- 研究的具体事物/现象

### 2. 研究方法
- 使用的技术/方法/模型

### 3. 研究结果
- 得出的结论/发现

### 4. 应用领域
- 技术/方法的应用场景

## 典型示例

**文献主题**：量子计算在密码学中的应用

**关键词**：
- 量子计算
- 密码学
- Shor算法
- 量子密钥分发
- 信息安全

## 答题技巧

1. 关键词数量一般控制在5-8个
2. 过于宽泛的词不作为关键词
3. 关键词要有代表性
4. 按照重要程度排序

## 易错点

- 选择过于宽泛的词
- 遗漏核心技术/方法
- 关键词数量过多或过少
- 关键词与文献主题无关
