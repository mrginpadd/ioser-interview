# 请求并发控制

## 【应用场景】
| 场景 | 说明 |
|------|------|
| **列表图片加载** | 一次性加载多张图片时限制并发数 |
| **批量上传文件** | 同时上传多个文件时控制并发数 |
| **API批量请求** | 批量获取数据时避免请求过多 |
| **性能优化** | 防止网络请求过多导致内存/CPU飙升 |
| **服务器保护** | 避免短时间内大量请求压垮服务器 |

## 【实现思路】

```
┌─────────────────────────────────────────────────────┐
│              请求并发控制实现思路                       │
│                                                     │
│  1. 任务队列管理                                      │
│     - 使用NSMutableArray维护等待队列                   │
│     - 当前执行中的任务数量不超过最大并发数              │
│                                                     │
│  2. 并发数控制                                        │
│     - 每次请求前检查当前执行数是否 < 最大并发数          │
│     - 如果达到上限，任务加入等待队列                    │
│                                                     │
│  3. 任务完成回调                                      │
│     - 任务完成后，从执行队列移除                       │
│     - 检查等待队列是否有等待任务                       │
│     - 如果有，从队列头部取出任务开始执行                │
│                                                     │
│  4. 线程安全                                          │
│     - 使用@synchronized或串行队列保护共享资源           │
│     - 保证队列操作的原子性                            │
│                                                     │
│  5. 任务状态管理                                      │
│     - 记录每个任务的状态（等待、执行中、完成、失败）     │
│     - 支持取消单个任务或所有任务                       │
└─────────────────────────────────────────────────────┘
```

**核心原理：**
- **队列管理**：等待队列 + 执行队列，控制并发数
- **信号量机制**：使用dispatch_semaphore_t控制并发数
- **任务回调**：任务完成后自动触发下一个任务

## 【代码题】
**题目：** 请实现请求并发控制，限制同时发送的网络请求数量？

**代码示例：**

```objective-c
// ConcurrentRequestManager.h
#import <Foundation/Foundation.h>

typedef void(^RequestCompletion)(id data, NSError *error);

@interface RequestTask : NSObject

@property (nonatomic, copy, readonly) NSString *url;
@property (nonatomic, copy) RequestCompletion completion;

@end

@interface ConcurrentRequestManager : NSObject

@property (nonatomic, assign) NSInteger maxConcurrentCount; // 默认4

+ (instancetype)sharedManager;

- (RequestTask *)addRequestWithURL:(NSString *)urlStr 
                        completion:(RequestCompletion)completion;

- (void)cancelTask:(RequestTask *)task;
- (void)cancelAllTasks;

@end

// ConcurrentRequestManager.m
#import "ConcurrentRequestManager.h"

@interface RequestTask ()

@property (nonatomic, strong) NSURLSessionDataTask *dataTask;
@property (nonatomic, assign) BOOL isCancelled;

@end

@implementation RequestTask

@end

@interface ConcurrentRequestManager ()

@property (nonatomic, strong) NSURLSession *session;
@property (nonatomic, strong) NSMutableArray *waitingQueue;
@property (nonatomic, strong) NSMutableArray *executingQueue;
@property (nonatomic, strong) dispatch_queue_t queue;
@property (nonatomic, strong) dispatch_semaphore_t semaphore;

@end

@implementation ConcurrentRequestManager

+ (instancetype)sharedManager {
    static ConcurrentRequestManager *manager = nil;
    static dispatch_once_t onceToken;
    dispatch_once(&onceToken, ^{
        manager = [[ConcurrentRequestManager alloc] init];
    });
    return manager;
}

- (instancetype)init {
    if (self = [super init]) {
        _maxConcurrentCount = 4;
        _waitingQueue = [[NSMutableArray alloc] init];
        _executingQueue = [[NSMutableArray alloc] init];
        _queue = dispatch_queue_create("com.concurrent.request", DISPATCH_QUEUE_SERIAL);
        
        // 信号量，初始值为最大并发数
        _semaphore = dispatch_semaphore_create(_maxConcurrentCount);
        
        NSURLSessionConfiguration *config = [NSURLSessionConfiguration defaultSessionConfiguration];
        _session = [NSURLSession sessionWithConfiguration:config delegate:nil delegateQueue:nil];
    }
    return self;
}

- (void)setMaxConcurrentCount:(NSInteger)maxConcurrentCount {
    _maxConcurrentCount = maxConcurrentCount;
    // 更新信号量
    _semaphore = dispatch_semaphore_create(maxConcurrentCount);
}

- (RequestTask *)addRequestWithURL:(NSString *)urlStr 
                        completion:(RequestCompletion)completion {
    
    RequestTask *task = [[RequestTask alloc] init];
    task.url = urlStr;
    task.completion = completion;
    
    // 串行队列中处理任务队列
    dispatch_async(_queue, ^{
        // 等待信号量
        dispatch_semaphore_wait(self->_semaphore, DISPATCH_TIME_FOREVER);
        
        if (task.isCancelled) {
            dispatch_semaphore_signal(self->_semaphore);
            return;
        }
        
        // 开始执行任务
        [self->_executingQueue addObject:task];
        
        // 在全局队列中执行网络请求
        dispatch_async(dispatch_get_global_queue(0, 0), ^{
            NSURL *url = [NSURL URLWithString:urlStr];
            NSURLSessionDataTask *dataTask = [self->_session dataTaskWithURL:url 
                completionHandler:^(NSData *data, NSURLResponse *response, NSError *error) {
                
                // 回调主线程
                dispatch_async(dispatch_get_main_queue(), ^{
                    if (task.completion) {
                        task.completion(data, error);
                    }
                });
                
                // 任务完成，释放信号量
                dispatch_async(self->_queue, ^{
                    [self->_executingQueue removeObject:task];
                    dispatch_semaphore_signal(self->_semaphore);
                });
            }];
            
            task.dataTask = dataTask;
            [dataTask resume];
        });
    });
    
    return task;
}

- (void)cancelTask:(RequestTask *)task {
    task.isCancelled = YES;
    [task.dataTask cancel];
    
    dispatch_async(_queue, ^{
        [_waitingQueue removeObject:task];
        [_executingQueue removeObject:task];
    });
}

- (void)cancelAllTasks {
    dispatch_async(_queue, ^{
        for (RequestTask *task in _executingQueue) {
            [task.dataTask cancel];
        }
        [_executingQueue removeAllObjects];
        [_waitingQueue removeAllObjects];
    });
}

@end

// 使用示例
#import "ConcurrentRequestManager.h"

// 设置最大并发数为3
[[ConcurrentRequestManager sharedManager] setMaxConcurrentCount:3];

// 批量添加10个请求
for (int i = 0; i < 10; i++) {
    NSString *urlStr = [NSString stringWithFormat:@"https://api.example.com/item/%d", i];
    
    [[ConcurrentRequestManager sharedManager] addRequestWithURL:urlStr 
        completion:^(id data, NSError *error) {
        if (error) {
            NSLog(@"请求%d失败: %@", i, error.localizedDescription);
            return;
        }
        NSLog(@"请求%d成功", i);
    }];
}
```

## 【设计要点】
- **信号量机制**：dispatch_semaphore_t控制并发数，初始值为最大并发数
- **串行队列**：使用串行队列保护共享资源（等待队列、执行队列）
- **任务状态**：记录每个任务的状态，支持取消操作
- **自动调度**：任务完成后自动释放信号量，触发下一个任务
- **灵活配置**：支持动态修改最大并发数
- **线程安全**：所有队列操作在串行队列中执行
