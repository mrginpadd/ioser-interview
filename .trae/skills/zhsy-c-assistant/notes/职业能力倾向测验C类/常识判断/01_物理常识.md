# 物理常识

## 力学

### 牛顿三大定律
1. **第一定律**：惯性定律，物体不受外力时保持静止或匀速直线运动
2. **第二定律**：F = ma，力等于质量乘以加速度
3. **第三定律**：作用力与反作用力大小相等、方向相反

### 常见力
- **重力**：G = mg，方向竖直向下
- **弹力**：接触产生，方向垂直接触面
- **摩擦力**：阻碍相对运动，分为静摩擦和动摩擦

## 电学

### 基本概念
- **电流**：I = Q/t，单位：安培(A)
- **电压**：U = IR，单位：伏特(V)
- **电阻**：R = ρL/S，单位：欧姆(Ω)

### 欧姆定律
I = U/R

### 电功率
P = UI = I²R = U²/R

## 光学

### 光的传播
- 光在同种均匀介质中沿直线传播
- 光的反射：入射角等于反射角
- 光的折射：从一种介质进入另一种介质时发生偏折

### 透镜成像
- **凸透镜**：会聚作用，可成放大/缩小实像
- **凹透镜**：发散作用，成虚像

## 热学

### 温度与热量
- **温度**：物体冷热程度的量度
- **热量**：Q = cmΔT，与质量、比热容、温度变化有关

### 物态变化
- 固态 → 液态：熔化（吸热）
- 液态 → 气态：汽化（吸热）
- 气态 → 液态：液化（放热）
- 液态 → 固态：凝固（放热）

## 典型例题

**例题**：下列关于力的说法，正确的是？
A. 物体不受力时一定静止
B. 物体受力时一定运动
C. 力的作用是相互的
D. 力可以脱离物体存在

**答案**：C

**解析**：
- A错误：物体不受力时可能做匀速直线运动
- B错误：受力平衡时可能静止
- C正确：符合牛顿第三定律
- D错误：力不能脱离物体存在
