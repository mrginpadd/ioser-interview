# 资料分析 - 综合分析

## 核心能力要求

资料分析综合考查以下能力：
1. 理解统计图表和数据材料
2. 快速准确计算
3. 分析比较不同数据
4. 综合判断和推理

## 常见数据类型

### 1. 增长率相关
- **同比增速**：与去年同期相比
- **环比增速**：与上一期相比
- **复合增长率**：(1+r)ⁿ - 1

### 2. 比重相关
- **直接比重**：部分÷整体
- **比重变化**：比较不同时期比重
- **贡献率**：部分增量÷整体增量

### 3. 倍数与平均数
- **倍数**：A是B的几倍 = A÷B
- **平均数**：总量÷总份数

## 典型综合分析题型

### 题型一：判断多项陈述正误
给出多条陈述，判断哪些正确

**解题思路**：
1. 逐条验证
2. 利用估算快速判断
3. 注意计算精度

### 题型二：计算最值
求最大/最小的增长率、比重等

**解题思路**：
1. 列出比较对象
2. 简化计算
3. 快速比较大小

### 题型三：推断结论
根据资料推出结论

**解题思路**：
1. 明确已知条件
2. 进行合理推导
3. 注意"一定"、"可能"等限定词

## 速算技巧

### 1. 截位法
将数字截取为近似值进行计算

**示例**：
- 12345 → 12300（截取百位）
- 8765 → 8800（截取百位）

### 2. 交叉法
用于增长率比较

### 3. 化同法
将分母化为相同进行比较

## 答题策略

1. **先看题目**：明确问题要求
2. **再看资料**：找到相关数据
3. **合理计算**：选择合适的速算方法
4. **验证答案**：确保计算正确

## 易错点

- 计算粗心导致错误
- 忽略题目限定条件
- 数据查找错误
- 过度计算浪费时间
