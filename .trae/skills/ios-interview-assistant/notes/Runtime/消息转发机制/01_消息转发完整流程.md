# 消息转发机制

## 【理论题】
**题目：** 请解释Objective-C消息转发的完整流程，以及每个阶段调用的方法？
**答案：**

**消息转发完整流程（5个阶段）：**

```
[obj doSomething]
    │
    ▼
┌─────────────────────────────────────────────────────┐
│  阶段1：快速查找（缓存）                               │
│  从类的方法缓存（cache）中查找                          │
│  找到 → 直接执行                                      │
│  没找到 → 进入阶段2                                    │
└──────────────────────┬──────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────┐
│  阶段2：慢速查找（方法列表）                           │
│  遍历类的方法列表（methodLists）                       │
│  找到 → 加入缓存，执行                                 │
│  没找到 → 沿superclass找父类，直到NSObject              │
│  都没找到 → 进入阶段3（消息转发开始）                    │
└──────────────────────┬──────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────┐
│  阶段3：动态方法解析                                   │
│  调用 +resolveInstanceMethod:                        │
│       或 +resolveClassMethod:                       │
│  返回YES → 已动态添加方法，重新查找                      │
│  返回NO → 进入阶段4                                    │
└──────────────────────┬──────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────┐
│  阶段4：备用接收者                                     │
│  调用 -forwardingTargetForSelector:                 │
│  返回对象 → 转发给该对象，重新走消息查找                 │
│  返回nil → 进入阶段5                                   │
└──────────────────────┬──────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────┐
│  阶段5：完整消息转发                                   │
│  a. 调用 -methodSignatureForSelector: 获取方法签名    │
│  b. 调用 -forwardInvocation: 转发NSInvocation        │
│  c. 都没实现 → 抛出doesNotRecognizeSelector:异常     │
└─────────────────────────────────────────────────────┘
```

**各阶段对应方法：**

| 阶段 | 实例方法 | 类方法 | 作用 |
|------|---------|--------|------|
| 动态方法解析 | `+resolveInstanceMethod:` | `+resolveClassMethod:` | 动态添加方法 |
| 备用接收者 | `-forwardingTargetForSelector:` | - | 转发给其他对象 |
| 完整消息转发 | `-methodSignatureForSelector:` + `-forwardInvocation:` | - | 完整转发 |

## 【场景题】
**题目：** 消息转发有什么实际应用场景？

**答案：**

| 场景 | 使用阶段 | 说明 |
|------|---------|------|
| **动态方法解析** | 阶段3 | @dynamic属性、CoreData |
| **多重代理** | 阶段4 | 转发给多个对象处理 |
| **热修复** | 阶段5 | JSPatch通过消息转发替换方法 |
| **防崩溃** | 阶段5 | 捕获unrecognized selector |
| **响应式编程** | 阶段3 | KVO动态生成子类 |

## 【代码示例】
```objective-c
// 1. 动态方法解析（阶段3）
#import <objc/runtime.h>

@implementation Person

+ (BOOL)resolveInstanceMethod:(SEL)sel {
    if (sel == @selector(run)) {
        class_addMethod(self, sel, (IMP)runImp, "v@:");
        return YES;
    }
    return [super resolveInstanceMethod:sel];
}

void runImp(id self, SEL _cmd) {
    NSLog(@"跑步");
}

@end

// 2. 备用接收者（阶段4）
@interface Dog : NSObject
- (void)bark;
@end

@implementation Person
- (id)forwardingTargetForSelector:(SEL)aSelector {
    if (aSelector == @selector(bark)) {
        return [[Dog alloc] init];  // 转发给Dog
    }
    return [super forwardingTargetForSelector:aSelector];
}
@end

// 3. 完整消息转发（阶段5）
@implementation Person

- (NSMethodSignature *)methodSignatureForSelector:(SEL)aSelector {
    if (aSelector == @selector(eat:)) {
        return [NSMethodSignature signatureWithObjCTypes:"v@:@"];
    }
    return [super methodSignatureForSelector:aSelector];
}

- (void)forwardInvocation:(NSInvocation *)anInvocation {
    SEL sel = anInvocation.selector;
    if ([self.dog respondsToSelector:sel]) {
        [anInvocation invokeWithTarget:self.dog];
    } else {
        [self doesNotRecognizeSelector:sel];
    }
}

@end
```

## 【答题要点】
- 消息转发分3个核心阶段：动态方法解析 → 备用接收者 → 完整消息转发
- 快速查找（缓存）和慢速查找（方法列表）是消息查找，不是消息转发
- 动态方法解析：resolveInstanceMethod:/resolveClassMethod:
- 备用接收者：forwardingTargetForSelector:
- 完整消息转发：methodSignatureForSelector: + forwardInvocation:
- 都没处理，最后抛doesNotRecognizeSelector异常
- 应用场景：动态方法、多重代理、热修复、防崩溃
