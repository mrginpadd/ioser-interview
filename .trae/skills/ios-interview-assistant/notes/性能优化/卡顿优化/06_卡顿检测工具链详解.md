# 卡顿检测工具链详解

## 【概念题】
**题目：** 如何使用Instruments检测App卡顿问题？

**答案：**

```
常用的Instruments工具：
├── Time Profiler：检测CPU耗时函数
├── Core Animation：检测渲染性能
├── Leaks：检测内存泄漏
├── Activity Monitor：监控CPU/内存/网络
└── System Trace：全面系统级追踪

检测流程：
1. 打开Xcode → Product → Profile
2. 选择对应的工具
3. 运行App，执行操作
4. 分析结果，定位问题
5. 修复问题，重复检测

Time Profiler使用：
├── 录制时执行卡顿操作
├── 选择主线程查看调用栈
├── 找到耗时最长的函数
├── 分析并优化

Core Animation使用：
├── Color Hits Green and Misses Red：检测缓存命中
├── Color Offscreen-Rendered Yellow：检测离屏渲染
├── Color Compositing Fastest Blue：检测混合操作
├── Color Blended Layers Red：检测透明混合
```

## 【场景题】
**题目：** 如何实现一个FPS监控工具？

**应用场景：**
```
FPS监控工具用于：
├── 实时监控App帧率变化
├── 检测卡顿问题（FPS < 50时报警）
├── 在开发阶段集成，帮助定位性能问题
├── 上线后收集性能数据，用于优化
```

**实现思路：**
```
核心原理：
├── 使用CADisplayLink监听屏幕刷新
├── CADisplayLink每帧回调一次tick方法
├── 在tick方法中统计每秒的帧数
├── FPS = 帧数 / 时间间隔（每秒计算一次）

实现步骤：
1. 创建单例类FPSMonitor
2. 在startMonitoring中创建CADisplayLink
3. 将CADisplayLink添加到主RunLoop
4. 在tick回调中统计帧数和时间
5. 每秒计算一次FPS并通过block回调
6. 在stopMonitoring中销毁CADisplayLink

关键技术点：
├── CADisplayLink：同步屏幕刷新的定时器
├── preferredFramesPerSecond：设置帧率（60fps）
├── timestamp：精确的时间戳
├── dispatch_once：保证单例唯一性
```

**代码实现：**

```objective-c
// FPS监控工具实现
@interface FPSMonitor : NSObject

@property (nonatomic, assign) CGFloat currentFPS;
@property (nonatomic, copy) void(^fpsUpdateBlock)(CGFloat fps);

+ (instancetype)sharedInstance;
- (void)startMonitoring;
- (void)stopMonitoring;

@end

@implementation FPSMonitor {
    CADisplayLink *_displayLink;
    NSInteger _frameCount;
    CFTimeInterval _lastTime;
}

+ (instancetype)sharedInstance {
    static FPSMonitor *instance = nil;
    static dispatch_once_t onceToken;
    dispatch_once(&onceToken, ^{
        instance = [[FPSMonitor alloc] init];
    });
    return instance;
}

- (void)startMonitoring {
    if (_displayLink) return;
    
    _displayLink = [CADisplayLink displayLinkWithTarget:self selector:@selector(tick:)];
    _displayLink.preferredFramesPerSecond = 60;
    [_displayLink addToRunLoop:[NSRunLoop mainRunLoop] forMode:NSRunLoopCommonModes];
}

- (void)stopMonitoring {
    [_displayLink invalidate];
    _displayLink = nil;
}

- (void)tick:(CADisplayLink *)link {
    if (_lastTime == 0) {
        _lastTime = link.timestamp;
        return;
    }
    
    _frameCount++;
    CFTimeInterval delta = link.timestamp - _lastTime;
    
    if (delta >= 1.0) {
        self.currentFPS = _frameCount / delta;
        
        if (self.fpsUpdateBlock) {
            self.fpsUpdateBlock(self.currentFPS);
        }
        
        _frameCount = 0;
        _lastTime = link.timestamp;
    }
}

@end

// 使用示例
[[FPSMonitor sharedInstance] startMonitoring];
[[FPSMonitor sharedInstance] setFpsUpdateBlock:^(CGFloat fps) {
    NSLog(@"FPS: %.1f", fps);
}];
```

## 【代码示例】

**应用场景：**
```
PerformanceMonitor用于：
├── 统一管理多种性能监控（FPS、内存）
├── 在App启动时自动开始监控
├── 在FPS过低时自动报警
├── 定期输出内存使用情况
```

**实现思路：**
```
实现步骤：
1. 创建PerformanceMonitor工具类
2. 在startMonitoring中启动FPSMonitor
3. 设置FPS回调，当FPS < 50时打印警告
4. 创建定时器定期获取内存使用情况
5. 使用task_info获取进程内存信息

关键技术点：
├── task_basic_info：获取进程基本信息
├── resident_size：常驻内存大小
├── mach_task_self()：当前进程任务
├── dispatch_source_create：创建定时器
```

**代码实现：**

```objective-c
// 性能监控工具类
@interface PerformanceMonitor : NSObject

+ (void)startMonitoring;
+ (void)stopMonitoring;

@end

@implementation PerformanceMonitor {
    static FPSMonitor *_fpsMonitor;
}

+ (void)startMonitoring {
    _fpsMonitor = [FPSMonitor sharedInstance];
    [_fpsMonitor startMonitoring];
    
    // 设置回调
    _fpsMonitor.fpsUpdateBlock = ^(CGFloat fps) {
        if (fps < 50) {
            NSLog(@"⚠️ 卡顿警告: FPS = %.1f", fps);
        }
    };
    
    // 监控内存
    [self startMemoryMonitoring];
}

+ (void)stopMonitoring {
    [_fpsMonitor stopMonitoring];
    [self stopMemoryMonitoring];
}

+ (void)startMemoryMonitoring {
    dispatch_source_t timer = dispatch_source_create(DISPATCH_SOURCE_TYPE_TIMER, 0, 0, dispatch_get_global_queue(DISPATCH_QUEUE_PRIORITY_DEFAULT, 0));
    dispatch_source_set_timer(timer, dispatch_time(DISPATCH_TIME_NOW, 0), 1.0 * NSEC_PER_SEC, 0);
    dispatch_source_set_event_handler(timer, ^{
        struct task_basic_info info;
        mach_msg_type_number_t size = sizeof(info);
        kern_return_t kerr = task_info(mach_task_self(), TASK_BASIC_INFO, (task_info_t)&info, &size);
        
        if (kerr == KERN_SUCCESS) {
            CGFloat memoryUsage = info.resident_size / (1024.0 * 1024.0);
            NSLog(@"内存使用: %.2f MB", memoryUsage);
        }
    });
    dispatch_resume(timer);
}

+ (void)stopMemoryMonitoring {
    // 停止内存监控
}

@end
```
