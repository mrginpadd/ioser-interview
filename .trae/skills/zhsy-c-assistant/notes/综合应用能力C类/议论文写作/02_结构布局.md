# 议论文结构布局

## 基本结构：引论-本论-结论

### 引论（10%-15%字数）
- **作用**：提出问题，引出论点
- **方法**：
  - 开门见山，直接点题
  - 引用名言/事例引入
  - 提出问题引发思考

### 本论（70%-80%字数）
- **作用**：论证中心论点
- **结构类型**：

#### 并列式
从不同角度并列论证

**示例**：
```
一、科技创新需要制度保障
二、科技创新需要人才支撑
三、科技创新需要文化氛围
```

#### 递进式
层层深入，逐步推进

**示例**：
```
一、问题表现：创新能力不足
二、原因分析：体制机制障碍
三、解决对策：深化改革
```

#### 对比式
正反对比论证

**示例**：
```
一、正面案例：创新驱动发展成功经验
二、反面教训：因循守旧导致发展停滞
三、启示与对策
```

### 结论（10%-15%字数）
- **作用**：总结全文，升华主题
- **方法**：
  - 总结主要观点
  - 展望未来
  - 发出呼吁

## 字数分配参考（800字）
- 引论：100-120字
- 本论：560-600字（3段，每段180-200字）
- 结论：100-120字

## 答题技巧

1. 结构要清晰，层次要分明
2. 每段要有明确的主题句
3. 段落之间要有过渡衔接
4. 首尾呼应，强化主题

## 易错点

- 结构混乱，逻辑不清
- 段落过长或过短
- 各部分比例失衡
- 缺乏过渡和衔接
