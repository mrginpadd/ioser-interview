# 图形推理

## 考查类型

### 1. 数量规律
- **点**：交点数、顶点数
- **线**：线段数、曲线数
- **面**：封闭区域数
- **角**：直角、锐角、钝角数量

### 2. 位置规律
- **平移**：图形在平面内移动
- **旋转**：图形绕某点旋转
- **翻转**：图形沿某轴翻转
- **叠加**：图形的重叠与分离

### 3. 样式规律
- **对称**：轴对称、中心对称
- **曲直**：曲线、直线
- **开闭**：开放、封闭

### 4. 空间重构
- **折纸盒**：判断展开图能否折成正方体
- **截面图**：判断物体的截面形状
- **三视图**：判断正视图、侧视图、俯视图

## 解题思路

### 步骤1：观察图形特征
- 图形组成是否相似
- 元素是否完全相同
- 是否有共同元素

### 步骤2：判断规律类型
- 元素相同 → 位置规律
- 元素相似 → 样式规律
- 元素不同 → 数量规律
- 立体图形 → 空间重构

### 步骤3：验证规律并选择答案

## 典型规律

### 数线段
```
□ △ ☆
第一个图形：4条线
第二个图形：3条线
第三个图形：5条线（答案：5条线的图形）
```

### 旋转
```
→ ↓ ← ↑
每次顺时针旋转90°
```

### 对称
```
★ ☆ ★ ☆ ★
轴对称图形
```

## 答题技巧

1. 先整体观察，再局部分析
2. 注意规律的延续性和周期性
3. 复杂图形可以使用排除法
4. 空间重构可以用排除法快速锁定答案

## 易错点

- 数错数量（尤其是复杂图形）
- 忽略多种规律的综合应用
- 空间想象能力不足导致错误
