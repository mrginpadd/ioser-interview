# 内存修饰符本质差异

## 核心原理

所有内存修饰符的本质差异，在于编译器在**setter方法中插入的语句不同**。

---

## 各修饰符对比

### 1. strong（强引用）

```objective-c
- (void)setObject:(NSObject *)object {
    if (_object != object) {
        [_object release];      // 释放旧值
        _object = [object retain];  // retain新值，引用计数+1
    }
}
```

**特点**：持有对象，引用计数+1

---

### 2. weak（弱引用）

```objective-c
- (void)setObject:(NSObject *)object {
    objc_storeWeak(&_object, object);  // 注册到side table，不retain
}
```

**特点**：不持有对象，引用计数不变，对象释放后自动置nil

---

### 3. assign（简单赋值）

```objective-c
- (void)setAge:(NSInteger)age {
    _age = age;  // 直接赋值，不涉及引用计数
}
```

**特点**：简单赋值，不涉及引用计数，适用于基本数据类型

---

### 4. copy（拷贝语义）

```objective-c
- (void)setName:(NSString *)name {
    if (_name != name) {
        [_name release];      // 释放旧值
        _name = [name copy];  // 创建副本
    }
}
```

**特点**：创建对象副本，防止外部修改影响属性值

---

### 5. retain（强引用，MRC时代）

```objective-c
- (void)setObject:(NSObject *)object {
    if (_object != object) {
        [_object release];
        _object = [object retain];
    }
}
```

**特点**：与strong完全相同，ARC下strong是默认值

---

### 6. unsafe_unretained（不安全的弱引用）

```objective-c
- (void)setObject:(NSObject *)object {
    _object = object;  // 直接赋值，不retain，不注册到side table
}
```

**特点**：不持有对象，但对象释放后**不会自动置nil**，会变成野指针

---

### 7. readonly（只读）

```objective-c
// 只生成getter方法，不生成setter方法
- (NSObject *)object {
    return _object;
}
```

**特点**：只有getter，没有setter，属性值不可修改

---

### 8. readwrite（读写，默认）

```objective-c
// 同时生成getter和setter方法
- (NSObject *)object {
    return _object;
}

- (void)setObject:(NSObject *)object {
    _object = [object retain];
}
```

**特点**：同时有getter和setter（默认行为）

---

### 9. getter= / setter=（自定义方法名）

```objective-c
@property (nonatomic, getter=isValid) BOOL valid;

// 生成的getter方法名变为isValid
- (BOOL)isValid {
    return _valid;
}
```

**特点**：自定义getter或setter方法名

---

## 本质差异速查表

| 修饰符 | setter插入语句 | 引用计数 | 对象释放后 | 适用类型 |
|--------|---------------|----------|-----------|----------|
| **strong** | `retain` | +1 | 野指针 | OC对象（ARC默认） |
| **weak** | `objc_storeWeak` | 不变 | 自动置nil | OC对象（避免循环引用） |
| **assign** | 直接赋值 | 不变 | 野指针 | 基本数据类型（int、float、NSInteger等） |
| **copy** | `copy` | +1（副本） | 野指针 | NSString、NSArray、NSDictionary等 |
| **retain** | `retain` | +1 | 野指针 | OC对象（MRC时代） |
| **unsafe_unretained** | 直接赋值 | 不变 | 野指针 | OC对象（不推荐，可能野指针） |
| **readonly** | 不生成setter | - | - | 只读属性 |
| **readwrite** | 生成完整setter | - | - | 读写属性（默认） |
| **getter=xxx** | 自定义getter名 | - | - | 布尔值常用 |

---

## 选择建议

```objective-c
// 持有对象 → strong（ARC默认）
@property (nonatomic, strong) NSObject *data;

// 避免循环引用 → weak
@property (nonatomic, weak) id<Delegate> delegate;
@property (nonatomic, weak) UIView *parentView;

// 基本数据类型 → assign
@property (nonatomic, assign) NSInteger count;
@property (nonatomic, assign) CGFloat height;

// 不可变对象防止外部修改 → copy
@property (nonatomic, copy) NSString *name;
@property (nonatomic, copy) NSArray *items;

// 只读属性 → readonly
@property (nonatomic, strong, readonly) NSString *identifier;

// 布尔值常用 → getter=
@property (nonatomic, getter=isValid) BOOL valid;

// MRC时代（已淘汰）→ retain
@property (nonatomic, retain) NSObject *object;

// 不安全的弱引用（不推荐）→ unsafe_unretained
@property (nonatomic, unsafe_unretained) NSObject *legacyObject;
```

---

## 关键要点

- **strong** = retain，持有对象（ARC默认）
- **weak** = 不持有，自动置nil（避免循环引用）
- **assign** = 直接赋值，无引用计数（基本数据类型）
- **copy** = 创建副本，保护数据完整性（不可变对象）
- **retain** = 与strong相同（MRC时代）
- **unsafe_unretained** = 不持有，不会自动置nil（不推荐）
- **readonly** = 只生成getter，不生成setter
- **getter=xxx** = 自定义getter方法名（布尔值常用）
- 选择修饰符的核心：是否需要持有、是否需要保护数据、是否需要避免循环引用
