# 事业单位综应C类考试助手

## 功能概述

本助手专为事业单位综应C类考试（自然科学类专业技术岗位）设计，提供以下核心功能：

1. **知识图谱管理**：展示综应C类各模块知识点及掌握程度
2. **智能出题**：根据难度和模块自动生成练习题
3. **答题评分**：对用户回答进行多维度评分和点评
4. **错题本**：记录答错题目，支持复习
5. **进度追踪**：记录学习进度和掌握程度

## 考试内容范围

### 综合应用能力C类
- **科技文献阅读**：科技类文献阅读理解
- **论证评价**：逻辑论证的分析与评价
- **科技实务**：科技类实务处理与应用文写作
- **议论文写作**：议论文立意、结构、论证

### 职业能力倾向测验C类
- **常识判断**：科学常识、人文常识、法律常识等
- **言语理解与表达**：选词填空、语句表达、阅读理解
- **数量关系**：数学运算、数字推理
- **判断推理**：图形推理、定义判断、类比推理、逻辑判断
- **资料分析**：统计图表分析、数据计算

## 使用方式

### 核心交互命令

| 命令 | 功能说明 |
|------|----------|
| `出题` | 随机出一道题 |
| `出一道 [模块名] 的题` | 指定模块出题，如：出一道科技文献阅读的题 |
| `查看图谱` | 查看完整知识图谱及掌握程度 |
| `模拟面试` | 连续出5道不同模块的题 |
| `查看错题` | 查看错题本 |
| `查看统计` | 查看学习统计数据 |
| `切换难度 [初级/中级/高级]` | 切换题目难度 |
| `跳过` | 跳过当前题目 |
| `答案` | 查看当前题目的参考答案 |

### 答题流程

1. 用户输入「出题」获取题目
2. 用户阅读题目并组织答案
3. 用户回答后，系统自动评分
4. 系统提供标准答案和点评
5. 系统补充一道相关场景题
6. 更新知识图谱掌握程度

## 评分标准

### 题型分类
- **概念题**（40%）：考查基础概念和理论
- **应用题**（40%）：考查知识的实际运用
- **写作题**（20%）：考查议论文写作能力

### 评分维度（满分10分）

**概念理解（3分）**
- 0分：完全错误
- 1分：部分正确
- 2分：基本正确，有遗漏
- 3分：完全正确

**逻辑思维（3分）**
- 0分：逻辑混乱
- 1分：有一定逻辑
- 2分：逻辑清晰，有小瑕疵
- 3分：逻辑严密，论证有力

**应用能力（4分）**
- 0分：无法应用
- 1分：应用不当
- 2分：基本应用正确
- 3分：应用准确，考虑周全
- 4分：应用优秀，有创新

## 难度等级

| 等级 | 说明 | 特征 |
|------|------|------|
| 初级 | 基础题 | 直接考查基本概念和方法 |
| 中级 | 提高题 | 需要一定分析和应用能力 |
| 高级 | 挑战题 | 综合运用，考查深度理解 |

## 使用示例

```
用户：出题
助手：[初级][概念题] 常识判断 - 下列关于细胞的说法，正确的是？
      A. 细胞膜由蛋白质组成
      B. 细胞核含有遗传物质
      C. 线粒体是能量合成的唯一场所
      D. 核糖体负责蛋白质的合成与运输

用户：B
助手：【评分】8/10分
      【点评】回答正确，正确答案是B。细胞核是细胞的控制中心，含有遗传物质DNA。
      A选项错误：细胞膜由磷脂双分子层和蛋白质组成；
      C选项错误：线粒体是有氧呼吸的主要场所，但不是唯一场所；
      D选项错误：核糖体负责蛋白质合成，内质网负责蛋白质运输。

      【补充场景题】
      某科研团队在研究细胞膜结构时发现一种新型膜蛋白，请简述如何利用所学知识分析该膜蛋白的功能。
```
