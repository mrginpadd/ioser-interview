# 单例模式

## 【理论题】
**题目：** 请解释单例模式的作用，以及如何用Objective-C实现一个线程安全的单例？
**答案：**

**单例模式：**

**单例模式确保一个类只有一个实例，并提供全局访问点。**

**应用场景：**
1. 频繁使用的对象（避免重复创建销毁）
2. 全局配置对象（如UserDefaults、NotificationCenter）
3. 资源共享对象（如网络请求管理、数据库管理）
4. 状态管理对象（如App状态、用户信息）

**线程安全的单例实现（推荐）：**

```objective-c

// 使用示例
Singleton *instance1 = [Singleton sharedInstance];
Singleton *instance2 = [Singleton sharedInstance];
NSLog(@"instance1 == instance2: %d", instance1 == instance2);  // YES

// 测试allocWithZone:防御性编程
// 如果没有重写allocWithZone:，这会创建第二个实例！
// 重写后，返回的是同一个实例
Singleton *allocInstance = [[Singleton alloc] init];
NSLog(@"sharedInstance == allocInstance: %d", [[Singleton sharedInstance] == allocInstance]);  // YES



// 推荐写法：dispatch_once
@interface Singleton : NSObject

+ (instancetype)sharedInstance;

@end

// 测试线程安全
dispatch_queue_t queue = dispatch_get_global_queue(0, 0);
for (int i = 0; i < 100; i++) {
    dispatch_async(queue, ^{
        Singleton *instance = [Singleton sharedInstance];
        NSLog(@"instance: %p", instance);  // 所有线程获取的是同一个实例
    });
}



@implementation Singleton

static Singleton *_sharedInstance = nil;

+ (instancetype)sharedInstance {
    static dispatch_once_t onceToken;
    dispatch_once(&onceToken, ^{
        _sharedInstance = [[self alloc] init];
    });
    return _sharedInstance;
}

// 防止通过alloc创建多个实例
+ (instancetype)allocWithZone:(struct _NSZone *)zone {
    static dispatch_once_t onceToken;
    dispatch_once(&onceToken, ^{
        _sharedInstance = [super allocWithZone:zone];
    });
    return _sharedInstance;
}

// 防止copy创建副本
- (id)copyWithZone:(NSZone *)zone {
    return _sharedInstance;
}

// 防止mutableCopy创建副本
- (id)mutableCopyWithZone:(NSZone *)zone {
    return _sharedInstance;
}

@end
```

**单例实现方式对比：**

| 方式 | 线程安全 | 性能 | 说明 |
|------|----------|------|------|
| `dispatch_once` | ✅ | 最优 | 推荐写法，只执行一次 |
| `dispatch_sync` | ✅ | 较差 | 每次调用都要加锁 |
| `@synchronized` | ✅ | 最差 | 每次调用都要加锁 |
| 无锁 | ❌ | 最快 | 线程不安全 |

## 【场景题】
**题目：** 在多线程环境下，为什么`dispatch_once`是线程安全的？

**答案：**

`dispatch_once`的底层实现是原子操作，保证只执行一次。

**原理：**
1. `onceToken`是一个全局变量，初始值为0
2. 第一次调用时，检查`onceToken`为0，执行block并将`onceToken`设置为1
3. 后续调用时，检查`onceToken`为1，直接跳过block
4. 整个过程是原子操作，不需要手动加锁

**优点：**
- 只加一次锁（第一次调用时）
- 后续调用直接返回，性能最优
- 线程安全，不需要担心竞态条件

## 【代码示例】
```objective-c
// 1. 基础单例
@interface NetworkManager : NSObject

+ (instancetype)sharedManager;

@end

@implementation NetworkManager

+ (instancetype)sharedManager {
    static NetworkManager *sharedInstance = nil;
    static dispatch_once_t onceToken;
    dispatch_once(&onceToken, ^{
        sharedInstance = [[self alloc] init];
    });
    return sharedInstance;
}

@end

// 2. 使用单例
NetworkManager *manager = [NetworkManager sharedManager];
[manager requestDataWithURL:@"http://example.com"];

// 3. Swift中的单例
class NetworkManager {
    static let shared = NetworkManager()
    private init() {}  // 防止外部创建
}
```

## 【答题要点】
- 单例确保一个类只有一个实例
- `dispatch_once`是线程安全的单例写法
- 需要重写`allocWithZone:`防止多次创建
- 需要重写`copyWithZone:`和`mutableCopyWithZone:`防止复制
- 单例常用于全局配置、资源共享、状态管理
- `dispatch_once`底层是原子操作，性能最优
