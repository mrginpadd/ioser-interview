# 类对象与元类

## 【理论题】
**题目：** 请解释类对象（Class）和元类（Meta-Class）的关系，以及为什么需要元类？
**答案：**

**类对象和元类的关系：**

```
┌─────────────────────────────────────────────────────┐
│                    对象（Instance）                   │
│  ┌─────────────────────────────────────────────┐   │
│  │  isa指针 ──────→ Class（类对象）             │   │
│  │  实例变量（ivar）                              │   │
│  └─────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────┐
│                    Class（类对象）                   │
│  ┌─────────────────────────────────────────────┐   │
│  │  isa指针 ──────→ Meta-Class（元类）           │   │
│  │  superclass指针 ─→ 父类                       │   │
│  │  方法列表（实例方法）                           │   │
│  │  属性列表、协议列表                            │   │
│  └─────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────┐
│                Meta-Class（元类）                   │
│  ┌─────────────────────────────────────────────┐   │
│  │  isa指针 ──────→ NSObject的元类（根元类）     │   │
│  │  superclass指针 ─→ 父类的元类                  │   │
│  │  方法列表（类方法）                             │   │
│  └─────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────┘
```

**为什么需要元类？**

> 在Objective-C中，**类方法也是通过消息机制调用的**。当调用`[Person alloc]`时，实际上是给Person类对象发送了alloc消息。为了让类对象能响应消息，需要一个地方存储类方法——这个地方就是元类。

**总结：**
- 对象的isa指向类对象（存储实例方法）
- 类对象的isa指向元类（存储类方法）
- 元类的isa指向根元类（NSObject的元类）
- 根元类的isa指向自己

## 【场景题】
**题目：** `[Person alloc]` 的调用流程是怎样的？

**答案：**

```
[Person alloc]调用流程：
1. Person是类对象（Class），它的isa指向Meta-Class
2. 查找alloc方法时，先在Person的方法列表（实例方法）找，没找到
3. 通过isa找到Meta-Class，在Meta-Class的方法列表（类方法）中找到alloc
4. 执行alloc方法，创建Person实例
```

## 【代码示例】
```objective-c
#import <objc/runtime.h>

// 1. 获取类对象
Class cls = [Person class];
Class cls2 = Person.class;
Class cls3 = object_getClass([Person alloc]);  // 返回Person类

// 2. 获取元类
Class metaCls = object_getClass(cls);  // 返回Person的元类

// 3. 验证isa指向
id obj = [[Person alloc] init];
Class objClass = object_getClass(obj);        // → Person（类对象）
Class clsMetaClass = object_getClass(cls);    // → Person的元类

// 4. 判断是否为元类
BOOL isMetaClass = class_isMetaClass(metaCls);  // → YES
BOOL isClass = class_isMetaClass(cls);          // → NO

// 5. 获取方法列表（从类对象获取实例方法）
unsigned int methodCount = 0;
Method *methods = class_copyMethodList(cls, &methodCount);
for (int i = 0; i < methodCount; i++) {
    SEL sel = method_getName(methods[i]);
    NSLog(@"实例方法：%@", NSStringFromSelector(sel));
}
free(methods);

// 6. 获取类方法列表（从元类获取）
Method *classMethods = class_copyMethodList(metaCls, &methodCount);
for (int i = 0; i < methodCount; i++) {
    SEL sel = method_getName(classMethods[i]);
    NSLog(@"类方法：%@", NSStringFromSelector(sel));
}
free(classMethods);

// 7. 获取父类
Class superCls = class_getSuperclass(cls);        // → NSObject
Class superMetaCls = class_getSuperclass(metaCls);  // → NSObject的元类

// 8. 根元类
Class rootMetaCls = object_getClass(NSObject.class);  // → NSObject的元类（根元类）
BOOL isRootMetaClass = class_isMetaClass(rootMetaCls) && 
                       class_getSuperclass(rootMetaCls) == nil;  // → YES

// 9. 验证isa链
// 对象 → 类对象 → 元类 → 根元类 → 根元类（指向自己）
```

## 【答题要点】
- 对象的isa指向类对象，类对象的isa指向元类
- 元类的作用：存储类方法
- 实例方法存储在类对象中，类方法存储在元类中
- `[Person alloc]` 实际上是给类对象发送消息，从元类中查找方法
- `object_getClass()` 获取对象的isa指向的类
- `class_isMetaClass()` 判断是否为元类
- 元类的继承链：子类元类 → 父类元类 → 根元类（NSObject的元类）
- 根元类的isa指向自己
- 类对象和元类都是objc_class结构体实例
