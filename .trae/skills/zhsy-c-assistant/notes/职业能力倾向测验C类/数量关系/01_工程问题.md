# 工程问题

## 核心公式

**工作总量** = 工作效率 × 工作时间

**工作效率** = 工作总量 ÷ 工作时间

**工作时间** = 工作总量 ÷ 工作效率

## 常见题型

### 1. 单人工作
一个人完成某项工作

### 2. 多人合作
多人同时工作，效率相加

### 3. 轮流工作
多人按顺序轮流工作

### 4. 增减效率
工作过程中效率变化

## 典型例题

**例题1**：甲单独完成一项工作需要10天，乙单独完成需要15天，两人合作需要几天？

**解析**：
- 设工作总量为1
- 甲效率 = 1/10，乙效率 = 1/15
- 合作效率 = 1/10 + 1/15 = 3/30 + 2/30 = 5/30 = 1/6
- 合作时间 = 1 ÷ (1/6) = 6天

**例题2**：甲乙丙三人合作一项工作，甲乙合作6天完成，乙丙合作10天完成，甲丙合作15天完成，问三人合作几天完成？

**解析**：
- 甲乙效率和 = 1/6
- 乙丙效率和 = 1/10
- 甲丙效率和 = 1/15
- 三式相加：2(甲+乙+丙) = 1/6 + 1/10 + 1/15 = 5/30 + 3/30 + 2/30 = 10/30 = 1/3
- 三人效率和 = 1/6
- 三人合作时间 = 6天

## 答题技巧

1. 设工作总量为1或最小公倍数
2. 合作效率等于各自效率之和
3. 注意"完成"的含义：完成工作总量的100%
4. 估算技巧：合作时间一定小于最快单独完成时间

## 易错点

- 效率不能直接相加时间
- 注意单位统一（天/小时/分钟）
- 多人合作时效率变化
- "完成一半"等特殊表述
