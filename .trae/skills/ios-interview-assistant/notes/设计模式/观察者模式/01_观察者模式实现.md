# 观察者模式

## 【理论题】
**题目：** 请解释观察者模式的作用，以及iOS中有哪些实现方式？
**答案：**

**观察者模式：实现一对多通信，一个对象状态变化时通知所有观察者。**

**iOS中三种实现方式：**

| 方式 | 特点 | 使用场景 |
|------|------|---------|
| **NSNotification** | 松耦合，一对多 | 全局事件通知 |
| **KVO** | 自动监听属性变化 | 监听属性变化 |
| **Delegate** | 一对一，强类型 | 表格视图交互 |

**三种方式对比：**

```
NSNotification（一对多，松耦合）
┌─────────────────────────────────────────────────────┐
│  NotificationCenter（通知中心）                      │
│  ┌──────┐  ┌──────┐  ┌──────┐                      │
│  │观察者1│  │观察者2│  │观察者3│                      │
│  └──┬───┘  └──┬───┘  └──┬───┘                      │
│     └─────────┼─────────┘                           │
│               ▼                                     │
│       发送者 postNotification                        │
└─────────────────────────────────────────────────────┘

KVO（一对一/一对多，自动监听）
┌─────────────────────────────────────────────────────┐
│  被观察对象.property 变化                             │
│         ▼                                            │
│  自动通知所有观察者                                   │
│  observeValueForKeyPath:                            │
└─────────────────────────────────────────────────────┘
```

## 【场景题】
**题目：** NSNotification和KVO的区别？如何选择？

**答案：**

| 特性 | NSNotification | KVO |
|------|---------------|-----|
| **监听对象** | 任意事件 | 特定属性变化 |
| **触发方式** | 手动post | 自动触发 |
| **耦合度** | 松耦合 | 紧耦合（需要知道被观察对象） |
| **性能** | 较低 | 较高 |
| **跨线程** | 支持 | 需要手动处理 |

**选择建议：**
- 监听属性变化 → KVO
- 全局事件通知 → NSNotification
- 一对一交互 → Delegate

## 【代码示例】
```objective-c
// 1. NSNotification（一对多）
// 发送通知
[[NSNotificationCenter defaultCenter] 
    postNotificationName:@"LoginSuccessNotification" 
                  object:nil 
                userInfo:@{@"userId": @"123"}];

// 监听通知
[[NSNotificationCenter defaultCenter] 
    addObserver:self 
    selector:@selector(loginSuccess:) 
    name:@"LoginSuccessNotification" 
    object:nil];

// 处理通知
- (void)loginSuccess:(NSNotification *)notification {
    NSDictionary *userInfo = notification.userInfo;
    NSLog(@"登录成功，userId: %@", userInfo[@"userId"]);
}

// 移除通知
- (void)dealloc {
    [[NSNotificationCenter defaultCenter] removeObserver:self];
}

// 2. KVO（监听属性变化）
// 添加观察者
[self.person addObserver:self 
              forKeyPath:@"name" 
                 options:NSKeyValueObservingOptionNew 
                 context:nil];

// 处理变化
- (void)observeValueForKeyPath:(NSString *)keyPath 
                      ofObject:(id)object 
                        change:(NSDictionary *)change 
                       context:(void *)context {
    if ([keyPath isEqualToString:@"name"]) {
        NSLog(@"name changed to: %@", change[NSKeyValueChangeNewKey]);
    }
}

// 移除观察者
- (void)dealloc {
    [self.person removeObserver:self forKeyPath:@"name"];
}
```

## 【答题要点】
- 观察者模式实现一对多通信
- iOS三种实现：NSNotification、KVO、Delegate
- NSNotification松耦合，适合全局事件通知
- KVO自动监听属性变化，需要手动移除
- Delegate一对一，强类型
- 选择建议：属性变化用KVO，全局事件用通知，一对一用代理
