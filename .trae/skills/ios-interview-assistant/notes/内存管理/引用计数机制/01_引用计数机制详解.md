# 引用计数机制详解

## 【概念题】
**题目：** 请简述iOS中的引用计数机制？

**答案：**

```
┌─────────────────────────────────────────────────────┐
│  引用计数基本概念                                     │
├─────────────────────────────────────────────────────┤
│  retainCount：对象的引用计数器                        │
│  ├── 对象创建时retainCount = 1                       │
│  ├── retain：retainCount + 1                        │
│  ├── release：retainCount - 1                        │
│  ├── autorelease：延迟release（加入自动释放池）        │
│  └── retainCount = 0时，调用dealloc释放对象            │
├─────────────────────────────────────────────────────┤
│  MRC（手动引用计数）                                  │
│  ├── 手动调用retain/release/autorelease              │
│  ├── 需要管理对象生命周期                             │
│  └── 容易遗漏导致内存泄漏或野指针                     │
├─────────────────────────────────────────────────────┤
│  ARC（自动引用计数）                                  │
│  ├── 编译器自动插入retain/release/autorelease        │
│  ├── 不需要手动管理对象生命周期                       │
│  └── 仍需注意循环引用问题                             │
├─────────────────────────────────────────────────────┤
│  属性访问与引用计数                                   │
│  ├── @property(strong)：get时retain，set时旧值release │
│  ├── @property(weak)：不增加引用计数                 │
│  ├── @property(copy)：copy新对象，旧值release        │
│  └── @property(assign)：不增加引用计数（用于基本类型） │
├─────────────────────────────────────────────────────┤
│  weak引用的处理机制                                   │
│  ├── weak指针不增加引用计数                          │
│  ├── 对象释放时，weak指针自动置为nil                  │
│  ├── weak表：存储weak指针与对象的映射关系             │
│  └── 对象dealloc时，遍历weak表，将所有weak指针置nil    │
├─────────────────────────────────────────────────────┤
│  循环引用问题                                        │
│  ├── A strong引用B，B strong引用A                    │
│  ├── 两者retainCount都不为0，无法释放                 │
│  ├── 解决方案：一方使用weak引用                      │
│  └── 常见场景：delegate、block                       │
└─────────────────────────────────────────────────────┘
```

## 【场景题】
**题目：** ARC环境下，以下代码的引用计数变化过程是怎样的？

```objective-c
@property (nonatomic, strong) MyObject *obj1;
@property (nonatomic, weak) MyObject *obj2;

MyObject *temp = [[MyObject alloc] init]; // ①
self.obj1 = temp;                         // ②
self.obj2 = temp;                         // ③
temp = nil;                               // ④
self.obj1 = nil;                          // ⑤
```

**答案：**

```
① [[MyObject alloc] init]：retainCount = 1
② self.obj1 = temp：retainCount = 2（strong属性自动retain）
③ self.obj2 = temp：retainCount = 2（weak属性不增加）
④ temp = nil：retainCount = 1（局部变量释放）
⑤ self.obj1 = nil：retainCount = 0（strong属性自动release）
   → 调用dealloc，obj2自动置为nil
```

## 【代码示例】
```objective-c
// MRC模式
MyObject *obj = [[MyObject alloc] init]; // retainCount = 1
[obj retain];                           // retainCount = 2
[obj release];                          // retainCount = 1
[obj autorelease];                      // 延迟release，当前retainCount仍为1
// 自动释放池结束时，retainCount = 0，调用dealloc

// ARC模式
@property (nonatomic, strong) MyObject *strongObj;
@property (nonatomic, weak) MyObject *weakObj;

MyObject *obj = [[MyObject alloc] init]; // retainCount = 1
self.strongObj = obj;                    // retainCount = 2（编译器自动retain）
self.weakObj = obj;                      // retainCount = 2（weak不增加）

self.strongObj = nil;                    // retainCount = 1（编译器自动release）
// obj释放时，weakObj自动置为nil

// 属性setter方法的内部实现（ARC编译后）
- (void)setStrongObj:(MyObject *)strongObj {
    if (_strongObj != strongObj) {
        [_strongObj release];            // 释放旧值
        _strongObj = [strongObj retain]; // retain新值
    }
}

// weak引用的实现原理
// 1. weak指针被赋值时，注册到weak表
// 2. 对象dealloc时，遍历weak表
// 3. 将所有指向该对象的weak指针置为nil
```
