# 论证评价 - 逻辑谬误类型大全

## 一、论据相关谬误

### 1. 论据不充分
- **概念**：论据不足以完全支持论点
- **示例**：研究学者对热带地区的苔藓进行了研究分析，分析结果证明，他们发现了全新的种类。（仅凭苔藓研究不能证明"全新种类"的普遍性结论）

### 2. 不相干谬误
- **概念**：论据与论点在逻辑上缺乏相互关系
- **示例**：人工智能能够以类似于人的情感和人进行交流从而解决问题。可见，其维护成本高。（情感交流能力与维护成本无必然联系）

### 3. 诉诸权威
- **概念**：论证中滥用权威者的证言作为论据，以此论证某论点
- **示例**：G教授关于基因编译的研究成果发表在国际顶级期刊上，因此G教授的研究结论是科学的。（发表在顶级期刊不代表结论一定科学）

### 4. 诉诸无知
- **概念**：以某一命题未被证明或尚不能被证明为论据，去断言这一命题为真或假
- **示例**：目前没有人能证明这个产品是不安全的，因此这个产品是安全的。（未被证明≠不存在）

### 5. 虚假论据
- **概念**：论据违背了必须为真的逻辑前提
- **示例**：只有体力劳动的人是劳动者，因此体力劳动和脑力劳动的人都是劳动者。（前提虚假）

### 6. 矛盾论据
- **概念**：用来支撑论点的论据中至少包含一组相互矛盾或对立的命题
- **示例**：海洋变暖是不可逆的，需要数百年才能逆转，所以人类需要通过多重举措来缓解。（"不可逆"与"需要数百年才能逆转"矛盾）

### 7. 预期理由
- **概念**：引用自身的真实性尚待证明的判断作为论据，去证明论点的真实性
- **示例**：某机构猜测，预计到2025年房地产价格还有一大波上涨趋势，所以大家要赶快买房。（"猜测"的真实性未被证明）

### 8. 循环论证
- **概念**：论点的真实性需要论据来支持，而论据的真实性又拿论点来证明
- **示例**：他之所以长得胖，是因为他吃得比较多。他为什么吃得这么多，是因为他长得胖。（因果循环）

## 二、推理相关谬误

### 9. 非黑即白
- **概念**：在两个极端之间不恰当地二者择一
- **提示词**：不是……就是…… / 要么……要么……
- **示例**：人工智能系统要么成为推动社会发展的有力工具，要么就成为不法分子的帮凶。（忽略了其他可能性）

### 10. 过度推断
- **概念**：论点部分得出了比条件所给内容更深层次的结论
- **示例**：点读机能够帮助孩子更便捷的学习外语，因此点读机能对孩子学习带来巨大的帮助。（"便捷"推不出"巨大帮助"）

### 11. 偷换论点
- **概念**：违反同一律，用与原概念看似相近但实际内涵不同的概念去替换原概念
- **提示词**：也就是说、换句话说
- **示例**：某医院在6例"左冠状动脉起源于肺动脉"治疗中，手术死亡1例，也就是说，其病症的死亡率为16.7%。（"手术死亡率"偷换为"病症死亡率"）

### 12. 转移论题
- **概念**：违反同一律，偏离正题而转向另一问题
- **示例**：
  - 甲说："我认为公司应该提供免费水果，这样能提高员工的工作效率。"
  - 乙答："关于提供免费水果能否提高工作效率，我觉得这取决于水果的质量。"（偏离了"免费水果能否提高效率"的论题）

### 13. 绝对化表述
- **概念**：论点部分的语句表达过于绝对，造成了判断上的绝对化
- **提示词**：一定、肯定、必然、绝对
- **示例**：H公司通过融资成功上市，因此未来股票一定会大涨。（"融资上市"推不出"一定大涨"）

### 14. 自相矛盾
- **概念**：违反矛盾律，论据和论点前后矛盾
- **示例**：新型的抗流感药物使得人体病毒清除率明显提高，可见该药物对病毒清除的作用微小。（"明显提高"与"作用微小"矛盾）

### 15. 以偏概全
- **概念**：据某些个别的、特殊的、局部的前提得出普遍的、整体性的结论
- **示例**：某少数民族的部分人存在一些违法犯罪行为。可见，该少数民族的人都涉及违法犯罪。（部分≠全部）

### 16. 类比不当
- **概念**：本质不具有可比性或者缺少可比性的两种事物，被论述者简单地放在一起加以比较
- **识别方法**：
  - 因为A是"这样"，所以B也是"这样"
  - 因为A之前是"这样"，所以A之后也是"这样"
- **示例**：
  - 地球与月球都属于太阳系星体。既然地球上存在生物，因此月球上也应存在生物。（两者条件差异巨大）
  - 100年前的中国很落后，人民生活非常艰苦。所以，100年后的中国也很落后，人民生活也不会改善。（时间不同，条件变化）

## 三、因果相关谬误

### 17. 统计谬误
- **概念**：推理论证过程中，出现忽视数据特点、忽视数据关系、运算公式错误等问题
- **示例**：某国旅游产业2023年收入为20亿元，同比增加10%，可见，2024年收入为22亿元。（预测下一年不能简单套用增长率）

### 18. 强拉因果
- **概念**：将毫无因果关系的论据和论点生拉硬拽在一起
- **示例**：由于连续血糖测量系统能够快速帮助糖尿病人观测血糖升降，所以它的价格比较便宜。（功能与价格无必然因果）

### 19. 因果倒置
- **概念**：将原因和结果颠倒的一种逻辑错误
- **示例**：具核杆菌疫苗能为通过常规抗癌没有效果的人群带来希望，所以它能够利用具核杆菌的某些特性来攻击癌细胞。（"带来希望"是结果，不是原因）

### 20. 复合原因
- **概念**：结论由多个原因共同导致，但论证者只选择其中的一个原因作为解释
- **示例**：在经历小行星撞击后，胎盘哺乳动物迅速填补了生态位，这就是因为少了恐龙的竞争。（忽略了其他可能原因）

## 易错点汇总

| 谬误类型 | 关键特征 | 快速识别技巧 |
|---------|---------|------------|
| 论据不充分 | 论据无法覆盖论点所有方面 | 看论据是否全面 |
| 诉诸权威 | 专家≠该领域专家 | 看专家是否在论证领域 |
| 以偏概全 | 部分≠整体 | 看样本是否有代表性 |
| 绝对化表述 | 过于绝对的词汇 | 找"一定""必然"等词 |
| 偷换概念 | 概念内涵不同 | 看前后概念是否一致 |
| 强拉因果 | 无因果关系 | 看因果是否成立 |
| 类比不当 | 本质不同却类比 | 看两者是否真的可比 |
