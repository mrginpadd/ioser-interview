# 主线程阻塞原因与优化

## 【概念题】
**题目：** 为什么主线程阻塞会导致App卡顿？

**答案：**

```
iOS的UI渲染和用户交互都在主线程执行：
├── 主线程负责：UI更新、事件响应、动画执行
├── 屏幕刷新率：60fps，每帧16.67ms
├── 如果主线程被阻塞 >16.67ms，就会丢帧 → 卡顿

主线程阻塞的常见原因：
├── 网络请求（同步请求、回调在主线程）
├── 数据库操作（FMDB同步查询）
├── 复杂计算（大量循环、JSON解析）
├── 同步锁（@synchronized、dispatch_sync）
└── 磁盘I/O（文件读写）
```

## 【场景题】
**题目：** 如何避免在主线程执行耗时操作？

**答案：**

```objective-c
// 方案1：网络请求放到子线程
dispatch_async(dispatch_get_global_queue(DISPATCH_QUEUE_PRIORITY_DEFAULT, 0), ^{
    NSData *data = [NSData dataWithContentsOfURL:[NSURL URLWithString:@"https://example.com"]];
    dispatch_async(dispatch_get_main_queue(), ^{
        // 更新UI
        self.data = data;
    });
});

// 方案2：数据库操作放到子线程
dispatch_async(dispatch_get_global_queue(DISPATCH_QUEUE_PRIORITY_DEFAULT, 0), ^{
    FMResultSet *result = [self.db executeQuery:@"SELECT * FROM users"];
    NSMutableArray *users = [NSMutableArray array];
    while ([result next]) {
        [users addObject:[result resultDictionary]];
    }
    dispatch_async(dispatch_get_main_queue(), ^{
        self.users = users;
    });
});

// 方案3：复杂计算放到子线程
dispatch_async(dispatch_get_global_queue(DISPATCH_QUEUE_PRIORITY_DEFAULT, 0), ^{
    NSArray *sortedArray = [self.dataArray sortedArrayUsingComparator:^NSComparisonResult(id obj1, id obj2) {
        return [obj1 compare:obj2];
    }];
    dispatch_async(dispatch_get_main_queue(), ^{
        self.tableView.dataSource = sortedArray;
    });
});
```

## 【代码示例】
```objective-c
// ❌ 不好的做法：主线程同步网络请求
- (void)loadData {
    NSURL *url = [NSURL URLWithString:@"https://example.com/api/data"];
    NSData *data = [NSData dataWithContentsOfURL:url]; // 阻塞主线程！
    self.json = [NSJSONSerialization JSONObjectWithData:data options:0 error:nil];
}

// ✅ 好的做法：异步网络请求
- (void)loadData {
    NSURLRequest *request = [NSURLRequest requestWithURL:[NSURL URLWithString:@"https://example.com/api/data"]];
    NSURLSessionDataTask *task = [[NSURLSession sharedSession] dataTaskWithRequest:request completionHandler:^(NSData *data, NSURLResponse *response, NSError *error) {
        dispatch_async(dispatch_get_main_queue(), ^{
            self.json = [NSJSONSerialization JSONObjectWithData:data options:0 error:nil];
        });
    }];
    [task resume];
}

// ❌ 不好的做法：主线程同步锁
- (void)updateData {
    @synchronized(self) {
        // 耗时操作
        for (int i = 0; i < 10000; i++) {
            [self.data addObject:@(i)];
        }
    }
}

// ✅ 好的做法：使用异步队列
- (void)updateData {
    dispatch_async(dispatch_get_global_queue(DISPATCH_QUEUE_PRIORITY_DEFAULT, 0), ^{
        // 耗时操作
        for (int i = 0; i < 10000; i++) {
            [self.data addObject:@(i)];
        }
    });
}
```
