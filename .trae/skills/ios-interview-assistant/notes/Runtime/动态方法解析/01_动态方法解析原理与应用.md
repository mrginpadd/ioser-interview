# 动态方法解析

## 【理论题】
**题目：** 请解释动态方法解析（Dynamic Method Resolution）的作用和使用场景？
**答案：**

**动态方法解析是消息转发的第三阶段：**

```
消息转发流程：
┌─────────────────────────────────────────────────┐
│ 1. 快速查找（缓存）                              │
│ 2. 慢速查找（类方法列表）                         │
│ 3. 动态方法解析（resolveInstanceMethod:）        │
│ 4. 备用接收者（forwardingTargetForSelector:）    │
│ 5. 完整消息转发（methodSignatureForSelector:）   │
└─────────────────────────────────────────────────┘
```

**两个方法：**

| 方法 | 作用 |
|------|------|
| `+resolveInstanceMethod:` | 动态添加实例方法 |
| `+resolveClassMethod:` | 动态添加类方法 |

**返回YES表示成功添加，系统会重新查找该方法；返回NO进入下一阶段。**

## 【场景题】
**题目：** 动态方法解析的实际应用场景？

**答案：**

| 场景 | 说明 |
|------|------|
| **按需加载方法** | 只在需要时才添加方法实现，节省内存 |
| **处理未实现的方法** | 捕获未实现的方法调用，避免崩溃 |
| **Category中添加方法** | 动态为Category添加实现 |
| **国际化/本地化** | 根据语言动态切换方法实现 |

## 【代码示例】
```objective-c
#import <objc/runtime.h>

// 1. 动态添加实例方法
@interface DynamicClass : NSObject
@end

@implementation DynamicClass

+ (BOOL)resolveInstanceMethod:(SEL)sel {
    if (sel == @selector(dynamicMethod)) {
        // 添加动态方法
        class_addMethod([self class], 
                       sel, 
                       (IMP)dynamicMethodIMP, 
                       "v@:");  // 类型编码：void(id, SEL)
        return YES;
    }
    return [super resolveInstanceMethod:sel];
}

@end

// 动态方法实现
void dynamicMethodIMP(id self, SEL _cmd) {
    NSLog(@"动态方法被调用");
}

// 使用
DynamicClass *obj = [[DynamicClass alloc] init];
[obj dynamicMethod];  // 调用动态添加的方法

// 2. 动态添加类方法
@interface DynamicClass2 : NSObject
@end

@implementation DynamicClass2

+ (BOOL)resolveClassMethod:(SEL)sel {
    if (sel == @selector(classDynamicMethod)) {
        class_addMethod(object_getClass([self class]), 
                       sel, 
                       (IMP)classDynamicMethodIMP, 
                       "v@:");
        return YES;
    }
    return [super resolveClassMethod:sel];
}

@end

void classDynamicMethodIMP(id self, SEL _cmd) {
    NSLog(@"动态类方法被调用");
}

// 使用
[DynamicClass2 classDynamicMethod];

// 3. 处理未实现的方法
@interface SafeClass : NSObject
@end

@implementation SafeClass

+ (BOOL)resolveInstanceMethod:(SEL)sel {
    NSString *methodName = NSStringFromSelector(sel);
    
    // 如果方法名以"safe_"开头，提供默认实现
    if ([methodName hasPrefix:@"safe_"]) {
        class_addMethod([self class], 
                       sel, 
                       (IMP)safeDefaultIMP, 
                       "v@:");
        return YES;
    }
    
    NSLog(@"警告：方法 %@ 未实现", methodName);
    return [super resolveInstanceMethod:sel];
}

@end

void safeDefaultIMP(id self, SEL _cmd) {
    NSLog(@"安全默认实现");
}

// 4. 延迟加载方法
@interface LazyClass : NSObject
@end

@implementation LazyClass

+ (BOOL)resolveInstanceMethod:(SEL)sel {
    // 只在第一次调用时才加载实现
    static dispatch_once_t onceToken;
    dispatch_once(&onceToken, ^{
        // 加载复杂的方法实现
        // 可能是从网络下载、从文件读取等
    });
    
    if (sel == @selector(complexMethod)) {
        class_addMethod([self class], 
                       sel, 
                       (IMP)complexMethodIMP, 
                       "v@:");
        return YES;
    }
    return [super resolveInstanceMethod:sel];
}

@end

// 5. 类型编码说明
// "v@:" → void(id self, SEL _cmd)
// "i@:" → int(id self, SEL _cmd)
// "i@:i" → int(id self, SEL _cmd, int arg1)
// "@:@" → id(id self, SEL _cmd)
```

## 【答题要点】
- 动态方法解析是消息转发的第三阶段
- `+resolveInstanceMethod:` 添加实例方法
- `+resolveClassMethod:` 添加类方法
- 返回YES：系统重新查找该方法
- 返回NO：进入下一阶段（备用接收者）
- 应用场景：按需加载、处理未实现方法、Category扩展
- 类型编码："v@:"表示无返回值，"i@:i"表示返回int、一个int参数
- 使用class_addMethod添加方法实现
- 动态方法解析只在首次调用时触发，后续调用直接走缓存
