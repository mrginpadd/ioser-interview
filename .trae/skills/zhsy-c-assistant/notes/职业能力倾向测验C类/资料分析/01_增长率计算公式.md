# 增长率计算

## 核心公式

**增长率** = 增长量 ÷ 基期值 × 100%

**增长量** = 现期值 - 基期值

**基期值** = 现期值 ÷ (1 + 增长率)

**现期值** = 基期值 × (1 + 增长率)

## 常见题型

### 1. 同比增长率
与去年同期相比的增长率

### 2. 环比增长率
与上一期（如上月、上季度）相比的增长率

## 典型例题

**例题1**：某市2023年GDP为8000亿元，比2022年增加了800亿元，问2023年GDP增长率是多少？

**解析**：
- 增长量 = 800亿元
- 基期值 = 8000 - 800 = 7200亿元
- 增长率 = 800 ÷ 7200 × 100% ≈ 11.1%

**例题2**：某产品2024年销量为1200件，同比增长20%，问2023年销量是多少？

**解析**：
- 基期值 = 1200 ÷ (1 + 20%) = 1200 ÷ 1.2 = 1000件

## 答题技巧

1. 分清"现期"和"基期"
2. 注意"同比"与"环比"的区别
3. 计算时注意小数点位置
4. 选项差距大时可估算

## 易错点

- 增长率是增长量除以基期值，不是现期值
- "同比"是与去年同期比较，"环比"是与上一个时间周期比较
- 注意题目中"增加了"和"增加到"的区别
