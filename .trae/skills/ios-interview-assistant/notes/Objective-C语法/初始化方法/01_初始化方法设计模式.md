# 初始化方法设计模式

## 【理论题】
**题目：** 请解释Objective-C中初始化方法的设计模式，以及init和new的区别？
**答案：**

**初始化方法设计模式：**

```objective-c
- (instancetype)init {
    self = [super init];  // 调用父类初始化
    if (self) {           // 检查是否成功（父类可能返回nil或其他对象）
        // 初始化成员变量
        _name = @"默认名";
        _age = 0;
    }
    return self;          // 返回self（可能是子类对象）
}
```

**为什么要检查self？**
- 父类init可能返回nil（比如单例类）
- 父类init可能返回其他对象（类簇模式）
- 不检查会导致后续代码在nil上执行

**为什么初始化要用`_ivar`而不是`self.property`？**

```objective-c
// ❌ 错误：可能导致死循环或子类问题
- (instancetype)init {
    self = [super init];
    if (self) {
        self.name = @"默认名";  // 调用setter，可能触发副作用
    }
    return self;
}

// ✅ 正确：直接访问实例变量
- (instancetype)init {
    self = [super init];
    if (self) {
        _name = @"默认名";  // 直接赋值，不经过setter
    }
    return self;
}
```

**使用self.property的风险：**

| 风险 | 说明 | 是否一定发生 |
|------|------|-------------|
| **死循环** | setter中如果调用其他方法，可能再次进入init | 不一定，取决于setter实现 |
| **子类重写setter** | 子类可能在setter中依赖未初始化的属性 | 子类继承时可能发生 |
| **KVO通知** | 属性访问会触发KVO，此时对象可能还未完全初始化 | 如果有观察者则发生 |
| **副作用** | setter可能有额外逻辑（日志、验证、UI更新等），初始化时不应该触发 | 取决于setter实现 |

**具体例子：**

```objective-c
// 例1：死循环（不一定，但可能发生）
@interface MyClass : NSObject
@property (nonatomic, copy) NSString *name;
@end

@implementation MyClass
- (instancetype)init {
    self = [super init];
    if (self) {
        self.name = @"默认名";  // 调用setter
    }
    return self;
}

- (void)setName:(NSString *)name {
    _name = [name copy];
    [self doSomething];  // 如果doSomething中又调用了init...
}
@end

// 例2：子类问题（更常见）
@interface ChildClass : MyClass
@property (nonatomic, strong) SomeObject *helper;
@end

@implementation ChildClass
- (void)setName:(NSString *)name {
    [super setName:name];
    [self.helper processName:name];  // helper还没初始化！崩溃！
}
@end

// 例3：KVO问题
// 初始化时如果有观察者监听name属性，会触发KVO回调
// 但此时对象还没完全初始化，回调中访问其他属性可能崩溃

// 例4：副作用
// setter中可能有日志、网络请求、UI更新等逻辑
// 初始化时不应该触发这些
```

**init和new的区别：**

| 方法 | 本质 | 适用场景 |
|------|------|---------|
| **init** | 只初始化 | 需要先alloc再init |
| **new** | alloc + init | 一步创建并初始化 |

```objective-c
// 两种方式等价
Person *p1 = [[Person alloc] init];
Person *p2 = [Person new];
```

## 【场景题】
**题目：** 子类如何正确实现初始化方法？

**答案：**

```objective-c
// 父类
@interface Animal : NSObject
@property (nonatomic, copy) NSString *name;
- (instancetype)initWithName:(NSString *)name;
@end

@implementation Animal
- (instancetype)initWithName:(NSString *)name {
    self = [super init];
    if (self) {
        _name = [name copy];
    }
    return self;
}
- (instancetype)init {
    return [self initWithName:@"未知"];
}
@end

// 子类
@interface Dog : Animal
@property (nonatomic, assign) NSInteger age;
- (instancetype)initWithName:(NSString *)name age:(NSInteger)age;
@end

@implementation Dog
- (instancetype)initWithName:(NSString *)name age:(NSInteger)age {
    self = [super initWithName:name];  // 调用父类指定初始化器
    if (self) {
        _age = age;
    }
    return self;
}
- (instancetype)init {
    return [self initWithName:@"旺财" age:0];
}
@end
```

## 【代码示例】
```objective-c
// 1. 标准初始化方法
@interface Person : NSObject
@property (nonatomic, copy) NSString *name;
@property (nonatomic, assign) NSInteger age;

- (instancetype)init;
- (instancetype)initWithName:(NSString *)name;
- (instancetype)initWithName:(NSString *)name age:(NSInteger)age;
@end

@implementation Person

// 指定初始化器（主初始化方法）
- (instancetype)initWithName:(NSString *)name age:(NSInteger)age {
    self = [super init];
    if (self) {
        _name = [name copy];
        _age = age;
    }
    return self;
}

// 便利初始化器
- (instancetype)initWithName:(NSString *)name {
    return [self initWithName:name age:0];
}

// 便利初始化器
- (instancetype)init {
    return [self initWithName:@"未知" age:0];
}

@end

// 2. 使用
Person *p1 = [[Person alloc] init];
Person *p2 = [[Person alloc] initWithName:@"张三"];
Person *p3 = [[Person alloc] initWithName:@"李四" age:25];
Person *p4 = [Person new];  // 等价于[[Person alloc] init]

// 3. 类簇模式（初始化返回不同对象）
// NSString就是类簇，[NSString alloc]可能返回不同的子类
NSString *str1 = [NSString stringWithFormat:@"hello"];  // 可能是__NSCFString
NSString *str2 = [NSString stringWithUTF8String:"world"];  // 可能是__NSCFConstantString

// 4. 单例模式中的init
// 单例类的init可能返回同一个实例或nil
@implementation Singleton
+ (instancetype)sharedInstance {
    static Singleton *instance = nil;
    static dispatch_once_t onceToken;
    dispatch_once(&onceToken, ^{
        instance = [[self alloc] init];
    });
    return instance;
}

// 防止通过init创建新实例
- (instancetype)init {
    static Singleton *instance = nil;
    static dispatch_once_t onceToken;
    dispatch_once(&onceToken, ^{
        instance = [super init];
    });
    return instance;
}
@end

// 5. 返回nil的情况
- (instancetype)initWithData:(NSData *)data {
    self = [super init];
    if (self) {
        if (!data || data.length == 0) {
            return nil;  // 参数无效，返回nil
        }
        _data = [data copy];
    }
    return self;
}
```

## 【答题要点】
- 初始化模式：self = [super init]; if (self) {...}; return self;
- init和new等价：new = alloc + init
- 指定初始化器（Designated Initializer）是类的主初始化方法
- 子类初始化必须调用父类的指定初始化器
- 父类init可能返回nil或其他对象（类簇模式）
- 检查self可以防止在nil上执行代码
- 便利初始化器调用指定初始化器
- 单例类的init可能返回同一个实例
- 初始化失败应返回nil
