# 代理模式

## 【理论题】
**题目：** 请解释代理模式（Delegate）的作用，以及在iOS开发中如何实现代理模式？
**答案：**

**代理模式：实现一对一的通信，一个对象将某些操作委托给另一个对象处理。**

**代理模式三要素：**
1. **协议（Protocol）** - 定义代理需要实现的方法
2. **delegate属性（weak）** - 被代理对象持有代理的弱引用
3. **代理对象** - 遵循协议，实现具体逻辑

**为什么delegate要用weak？**

```
避免循环引用！
┌─────────────────────────────────────────────────────┐
│  ViewController  ──strong──→ View                   │
│  View            ──strong──→ ViewController（代理） │
│  ↕ 循环引用！两者都无法释放                          │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│  ViewController  ──strong──→ View                   │
│  View            ──weak───→ ViewController（代理）   │
│  ✅ 正确！ViewController可以正常释放                 │
└─────────────────────────────────────────────────────┘
```

## 【场景题】
**题目：** UITableView的delegate和dataSource的区别？

**答案：**

| 类型 | 作用 | 核心方法 |
|------|------|---------|
| **dataSource** | 提供数据 | `numberOfRowsInSection:`、`cellForRowAtIndexPath:` |
| **delegate** | 处理交互 | `didSelectRowAtIndexPath:`、`heightForRowAtIndexPath:` |

## 【代码示例】
```objective-c
// 1. 定义协议
@class CustomView;
@protocol CustomViewDelegate <NSObject>
@optional
- (void)customViewDidTap:(CustomView *)view;
- (void)customView:(CustomView *)view didScrollToIndex:(NSInteger)index;
@end

// 2. 被代理对象
@interface CustomView : UIView
// weak避免循环引用
@property (nonatomic, weak) id<CustomViewDelegate> delegate;
@end

@implementation CustomView

- (void)handleTap {
    // 调用代理方法前先判断是否实现
    if ([self.delegate respondsToSelector:@selector(customViewDidTap:)]) {
        [self.delegate customViewDidTap:self];
    }
}

@end

// 3. 代理对象
@interface ViewController : UIViewController <CustomViewDelegate>
@property (strong, nonatomic) CustomView *customView;
@end

@implementation ViewController

- (void)viewDidLoad {
    [super viewDidLoad];
    self.customView = [[CustomView alloc] init];
    self.customView.delegate = self;  // 设置代理
}

// 实现代理方法
- (void)customViewDidTap:(CustomView *)view {
    NSLog(@"CustomView被点击了");
}

- (void)customView:(CustomView *)view didScrollToIndex:(NSInteger)index {
    NSLog(@"滚动到索引: %ld", (long)index);
}

@end
```

## 【答题要点】
- 代理模式实现一对一通信
- 三要素：协议、delegate属性、代理对象
- delegate必须用weak，避免循环引用
- @optional方法调用前需用respondsToSelector:判断
- dataSource提供数据，delegate处理交互
- 常见应用：UITableView、UICollectionView、UITextField
