# 关联对象（Associated Objects）

## 【理论题】
**题目：** 请解释关联对象（Associated Objects）的作用和使用场景？
**答案：**

关联对象就是在不修改类定义的前提下，给对象"挂"一些额外数据。最常用的场景就是 Category 中添加属性 。

**关联对象的作用：**
> 关联对象（Associated Objects）可以在运行时为已有的类**动态添加属性**，而不需要修改类的定义。常用于Category中添加属性。

**使用场景：**

| 场景 | 说明 |
|------|------|
| **Category加属性** | 分类中不能直接加属性，用关联对象实现 |
| **KVO添加观察者** | 给对象关联一个观察者对象 |
| **UIKit分类加属性** | 给UIView/CALayer添加自定义属性 |
| **存储临时数据** | 不需要修改类结构时存储额外数据 |

**核心API：**

```objective-c
objc_setAssociatedObject()   // 设置关联对象
objc_getAssociatedObject()   // 获取关联对象
objc_removeAssociatedObjects() // 移除所有关联对象
```

**关联策略：**

| 策略 | 说明 | 对应@property |
|------|------|-------------|
| OBJC_ASSOCIATION_ASSIGN | assign引用 | assign |
| OBJC_ASSOCIATION_RETAIN_NONATOMIC | strong引用，非原子 | strong, nonatomic |
| OBJC_ASSOCIATION_COPY_NONATOMIC | copy引用，非原子 | copy, nonatomic |
| OBJC_ASSOCIATION_RETAIN | strong引用，原子 | strong, atomic |
| OBJC_ASSOCIATION_COPY | copy引用，原子 | copy, atomic |

## 【场景题】
**题目：** 为什么Category中要用关联对象加属性？

**答案：**

```
Category的局限性：
┌─────────────────────────────────────────────────────┐
│  Category只能添加方法，不能添加成员变量（ivar）        │
│  @property在Category中只会声明getter/setter方法      │
│  不会自动生成_ivar，也不会自动生成方法实现              │
│                                                      │
│  解决方案：用关联对象实现属性的getter/setter            │
└─────────────────────────────────────────────────────┘
```

## 【代码示例】
```objective-c
#import <objc/runtime.h>

// 1. Category中添加属性
@interface UIView (Custom)
@property (nonatomic, strong) NSString *tagName;
@end

@implementation UIView (Custom)

// 关联对象的key（用静态变量地址作为key，唯一）
static const void *kTagNameKey = &kTagNameKey;

- (NSString *)tagName {
    return objc_getAssociatedObject(self, kTagNameKey);
}

- (void)setTagName:(NSString *)tagName {
    objc_setAssociatedObject(self, kTagNameKey, tagName, OBJC_ASSOCIATION_RETAIN_NONATOMIC);
}

@end

// 2. 使用
UIView *view = [[UIView alloc] init];
view.tagName = @"标题视图";
NSLog(@"%@", view.tagName);

// 3. 多种关联策略示例
@interface Person (Associated)
@property (nonatomic, assign) NSInteger age;       // assign
@property (nonatomic, copy) NSString *name;        // copy
@property (nonatomic, strong) NSArray *friends;    // strong
@end

@implementation Person (Associated)

static const void *kAgeKey = &kAgeKey;
static const void *kNameKey = &kNameKey;
static const void *kFriendsKey = &kFriendsKey;

- (NSInteger)age {
    return [objc_getAssociatedObject(self, kAgeKey) integerValue];
}

- (void)setAge:(NSInteger)age {
    objc_setAssociatedObject(self, kAgeKey, @(age), OBJC_ASSOCIATION_ASSIGN);
}

- (NSString *)name {
    return objc_getAssociatedObject(self, kNameKey);
}

- (void)setName:(NSString *)name {
    objc_setAssociatedObject(self, kNameKey, name, OBJC_ASSOCIATION_COPY_NONATOMIC);
}

- (NSArray *)friends {
    return objc_getAssociatedObject(self, kFriendsKey);
}

- (void)setFriends:(NSArray *)friends {
    objc_setAssociatedObject(self, kFriendsKey, friends, OBJC_ASSOCIATION_RETAIN_NONATOMIC);
}

@end

// 4. 移除关联对象
objc_removeAssociatedObjects(self);  // 移除所有关联对象

// 5. 用@selector作为key（另一种写法）
- (NSString *)title {
    return objc_getAssociatedObject(self, @selector(title));
}

- (void)setTitle:(NSString *)title {
    objc_setAssociatedObject(self, @selector(title), title, OBJC_ASSOCIATION_COPY_NONATOMIC);
}
```

## 【答题要点】
- 关联对象用于在运行时动态给类添加属性
- 常用于Category中添加属性（Category不能直接加ivar）
- 核心API：objc_setAssociatedObject / objc_getAssociatedObject
- 关联策略：assign、retain nonatomic、copy nonatomic等
- 关联对象存储在全局的AssociationsManager哈希表中
- 对象释放时，关联对象会被自动释放
- 关联对象不是存在对象本身的内存中，而是在全局哈希表
