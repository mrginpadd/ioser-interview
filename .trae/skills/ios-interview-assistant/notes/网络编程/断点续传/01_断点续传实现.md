# 断点续传

## 【应用场景】
| 场景 | 说明 |
|------|------|
| **大文件下载** | 视频、安装包、文档等大文件下载 |
| **网络不稳定** | 移动网络下频繁断开重连 |
| **用户暂停** | 用户主动暂停下载，稍后继续 |
| **后台下载** | App进入后台后继续下载 |
| **多任务管理** | 同时管理多个下载任务 |

## 【实现思路】

```
┌─────────────────────────────────────────────────────┐
│              断点续传实现思路                         │
│                                                     │
│  1. 检查服务器是否支持Range请求                        │
│     - 发送HEAD请求，检查Accept-Ranges响应头            │
│                                                     │
│  2. 发送Range请求开始下载                             │
│     - Range: bytes=0- （首次下载）                    │
│     - Range: bytes=1000- （续传）                    │
│                                                     │
│  3. 下载过程中写入临时文件                            │
│     - 文件路径：xxx.tmp                              │
│     - 记录已下载字节数                                │
│                                                     │
│  4. 暂停时保存恢复数据                                │
│     - cancelByProducingResumeData获取resumeData      │
│     - 保存临时文件状态                                │
│                                                     │
│  5. 继续下载时合并文件                                │
│     - 读取旧临时文件内容                              │
│     - 追加新下载内容                                  │
│     - 写入最终文件                                    │
│                                                     │
│  6. 下载完成后清理临时文件                            │
│     - 删除.tmp文件                                    │
│     - 返回最终文件路径                                │
└─────────────────────────────────────────────────────┘
```

**核心原理：**
- **HTTP Range请求头**：告知服务器从哪个字节开始发送数据
- **临时文件存储**：下载过程中数据写入临时文件，避免未完成的文件影响用户
- **文件合并**：续传时读取旧文件+新下载内容合并成完整文件

## 【代码题】
**题目：** 请实现断点续传功能，支持暂停、继续下载？

**代码示例：**

```objective-c
// DownloadManager.h
#import <Foundation/Foundation.h>

typedef NS_ENUM(NSInteger, DownloadState) {
    DownloadStateWaiting,
    DownloadStateDownloading,
    DownloadStatePaused,
    DownloadStateCompleted,
    DownloadStateFailed
};

typedef void(^DownloadProgress)(NSProgress *progress);
typedef void(^DownloadCompletion)(NSString *filePath, NSError *error);

@interface DownloadTask : NSObject

@property (nonatomic, copy, readonly) NSString *url;
@property (nonatomic, copy, readonly) NSString *savePath;
@property (nonatomic, assign, readonly) DownloadState state;
@property (nonatomic, strong, readonly) NSProgress *progress;

@property (nonatomic, copy) DownloadProgress progressBlock;
@property (nonatomic, copy) DownloadCompletion completionBlock;

- (void)start;
- (void)pause;
- (void)resume;
- (void)cancel;

@end

@interface DownloadManager : NSObject

+ (instancetype)sharedManager;

- (DownloadTask *)downloadWithURL:(NSString *)urlStr 
                         savePath:(NSString *)savePath
                         progress:(DownloadProgress)progress
                       completion:(DownloadCompletion)completion;

- (DownloadTask *)taskForURL:(NSString *)urlStr;

@end

// DownloadTask.m
#import "DownloadManager.h"

@interface DownloadTask ()

@property (nonatomic, strong) NSURLSessionDownloadTask *downloadTask;
@property (nonatomic, strong) NSURLSession *session;
@property (nonatomic, assign) DownloadState internalState;
@property (nonatomic, assign) int64_t downloadedBytes;
@property (nonatomic, assign) int64_t totalBytes;
@property (nonatomic, strong) NSData *resumeData;

@end

@implementation DownloadTask

- (instancetype)initWithURL:(NSString *)url savePath:(NSString *)savePath {
    if (self = [super init]) {
        _url = url;
        _savePath = savePath;
        _internalState = DownloadStateWaiting;
        _progress = [[NSProgress alloc] init];
        
        // 检查是否有已下载的临时文件
        NSString *tempPath = [savePath stringByAppendingString:@".tmp"];
        if ([[NSFileManager defaultManager] fileExistsAtPath:tempPath]) {
            NSDictionary *attr = [[NSFileManager defaultManager] attributesOfItemAtPath:tempPath error:nil];
            _downloadedBytes = [attr[NSFileSize] longLongValue];
            _progress.completedUnitCount = _downloadedBytes;
        }
        
        NSURLSessionConfiguration *config = [NSURLSessionConfiguration backgroundSessionConfigurationWithIdentifier:url];
        _session = [NSURLSession sessionWithConfiguration:config delegate:self delegateQueue:nil];
    }
    return self;
}

- (DownloadState)state {
    return _internalState;
}

- (void)start {
    if (_internalState == DownloadStateDownloading) return;
    
    NSURL *url = [NSURL URLWithString:_url];
    
    if (_resumeData) {
        // 从断点继续
        _downloadTask = [_session downloadTaskWithResumeData:_resumeData];
    } else {
        // 新下载或从临时文件继续
        NSURLRequest *request = [NSURLRequest requestWithURL:url];
        if (_downloadedBytes > 0) {
            // 设置Range请求头，从已下载位置继续
            NSString *range = [NSString stringWithFormat:@"bytes=%lld-", (long long)_downloadedBytes];
            NSMutableURLRequest *mutableRequest = [request mutableCopy];
            [mutableRequest setValue:range forHTTPHeaderField:@"Range"];
            request = mutableRequest;
        }
        _downloadTask = [_session downloadTaskWithRequest:request];
    }
    
    _internalState = DownloadStateDownloading;
    [_downloadTask resume];
}

- (void)pause {
    if (_internalState != DownloadStateDownloading) return;
    
    [_downloadTask cancelByProducingResumeData:^(NSData *resumeData) {
        _resumeData = resumeData;
        _internalState = DownloadStatePaused;
    }];
    _downloadTask = nil;
}

- (void)resume {
    if (_internalState != DownloadStatePaused) return;
    [self start];
}

- (void)cancel {
    [_downloadTask cancel];
    _downloadTask = nil;
    _internalState = DownloadStateWaiting;
    _resumeData = nil;
    
    // 删除临时文件
    NSString *tempPath = [_savePath stringByAppendingString:@".tmp"];
    [[NSFileManager defaultManager] removeItemAtPath:tempPath error:nil];
}

#pragma mark - NSURLSessionDownloadDelegate

- (void)URLSession:(NSURLSession *)session 
      downloadTask:(NSURLSessionDownloadTask *)downloadTask 
      didWriteData:(int64_t)bytesWritten
 totalBytesWritten:(int64_t)totalBytesWritten
totalBytesExpectedToWrite:(int64_t)totalBytesExpectedToWrite {
    
    // 更新进度
    _downloadedBytes = totalBytesWritten + (_resumeData ? 0 : _downloadedBytes);
    _totalBytes = totalBytesExpectedToWrite;
    
    _progress.totalUnitCount = _totalBytes;
    _progress.completedUnitCount = _downloadedBytes;
    
    if (self.progressBlock) {
        dispatch_async(dispatch_get_main_queue(), ^{
            self.progressBlock(_progress);
        });
    }
}

- (void)URLSession:(NSURLSession *)session 
      downloadTask:(NSURLSessionDownloadTask *)downloadTask
didFinishDownloadingToURL:(NSURL *)location {
    
    // 将临时文件移动到最终位置
    NSString *tempPath = [_savePath stringByAppendingString:@".tmp"];
    
    // 如果是断点续传，需要合并文件
    if (_resumeData) {
        // 从临时文件读取已下载内容
        NSData *existingData = [NSData dataWithContentsOfFile:tempPath];
        // 读取新下载的内容
        NSData *newData = [NSData dataWithContentsOfURL:location];
        // 合并
        NSMutableData *combinedData = [NSMutableData dataWithData:existingData];
        [combinedData appendData:newData];
        // 写入最终文件
        [combinedData writeToFile:_savePath atomically:YES];
    } else {
        // 新下载，直接移动
        NSFileManager *fm = [NSFileManager defaultManager];
        [fm moveItemAtURL:location toURL:[NSURL fileURLWithPath:_savePath] error:nil];
    }
    
    // 删除临时文件
    [[NSFileManager defaultManager] removeItemAtPath:tempPath error:nil];
    
    _internalState = DownloadStateCompleted;
    
    if (self.completionBlock) {
        dispatch_async(dispatch_get_main_queue(), ^{
            self.completionBlock(_savePath, nil);
        });
    }
}

- (void)URLSession:(NSURLSession *)session 
              task:(NSURLSessionTask *)task
didCompleteWithError:(NSError *)error {
    
    if (error) {
        _internalState = DownloadStateFailed;
        
        // 如果是用户取消，不算失败
        if (error.code != NSURLErrorCancelled) {
            if (self.completionBlock) {
                dispatch_async(dispatch_get_main_queue(), ^{
                    self.completionBlock(nil, error);
                });
            }
        }
    }
}

@end

// DownloadManager.m
#import "DownloadManager.h"

@interface DownloadManager ()

@property (nonatomic, strong) NSMutableDictionary *tasks;

@end

@implementation DownloadManager

+ (instancetype)sharedManager {
    static DownloadManager *manager = nil;
    static dispatch_once_t onceToken;
    dispatch_once(&onceToken, ^{
        manager = [[DownloadManager alloc] init];
    });
    return manager;
}

- (instancetype)init {
    if (self = [super init]) {
        _tasks = [[NSMutableDictionary alloc] init];
    }
    return self;
}

- (DownloadTask *)downloadWithURL:(NSString *)urlStr 
                         savePath:(NSString *)savePath
                         progress:(DownloadProgress)progress
                       completion:(DownloadCompletion)completion {
    
    // 检查是否已有任务
    DownloadTask *task = [self taskForURL:urlStr];
    if (task) {
        // 更新回调
        task.progressBlock = progress;
        task.completionBlock = completion;
        return task;
    }
    
    // 创建新任务
    task = [[DownloadTask alloc] initWithURL:urlStr savePath:savePath];
    task.progressBlock = progress;
    task.completionBlock = completion;
    
    [_tasks setObject:task forKey:urlStr];
    
    return task;
}

- (DownloadTask *)taskForURL:(NSString *)urlStr {
    return [_tasks objectForKey:urlStr];
}

@end

// 使用示例
#import "DownloadManager.h"

// 下载文件
DownloadTask *task = [[DownloadManager sharedManager] downloadWithURL:@"https://example.com/large_file.zip"
                                                             savePath:[NSSearchPathForDirectoriesInDomains(NSDocumentDirectory, NSUserDomainMask, YES)[0] stringByAppendingPathComponent:@"file.zip"]
                                                             progress:^(NSProgress *progress) {
    NSLog(@"下载进度: %.2f%%", progress.fractionCompleted * 100);
} completion:^(NSString *filePath, NSError *error) {
    if (error) {
        NSLog(@"下载失败: %@", error.localizedDescription);
        return;
    }
    NSLog(@"下载完成: %@", filePath);
}];

// 开始下载
[task start];

// 暂停下载
[task pause];

// 继续下载
[task resume];

// 取消下载
[task cancel];
```

## 【实现原理】
- **断点续传核心：HTTP Range请求头**
  - `Range: bytes=1000-` 表示从第1000字节开始下载
- **临时文件存储：** 下载过程中数据写入`.tmp`文件
- **文件合并：** 续传时读取旧文件+新下载内容合并
- **NSURLSessionDownloadDelegate：** 监听下载进度和完成
- **resumeData：** 暂停时生成恢复数据，下次继续使用

## 【设计要点】
- 下载状态管理：waiting、downloading、paused、completed、failed
- 进度回调：实时更新下载进度
- 暂停/继续：cancelByProducingResumeData生成恢复数据
- 文件合并：断点续传时合并旧文件和新内容
- 临时文件：下载过程中使用.tmp后缀
- 后台下载：使用backgroundSessionConfiguration
- 单例管理：DownloadManager统一管理所有下载任务

## 【注意事项】
- 服务器必须支持Range请求头
- 临时文件需要定期清理
- 进度计算要考虑已下载的字节数
- 后台下载需要配置AppDelegate
