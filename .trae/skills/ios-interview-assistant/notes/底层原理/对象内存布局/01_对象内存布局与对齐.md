# 对象内存布局

## 【理论题】
**题目：** 请解释Objective-C对象的内存布局，包括isa指针、实例变量、对齐方式？
**答案：**

**Objective-C对象内存布局：**

```
┌─────────────────────────────────────────────────────┐
│                   对象内存布局                        │
│                                                     │
│  ┌─────────────────┐  ← 起始地址                    │
│  │    isa指针       │  8字节（64位）/ 4字节（32位）   │
│  ├─────────────────┤                                │
│  │    实例变量1     │  根据类型定长                  │
│  │    实例变量2     │  int: 4字节, long: 8字节       │
│  │    ...          │  pointer: 8字节                │
│  ├─────────────────┤                                │
│  │    对齐填充      │  确保16字节对齐                │
│  └─────────────────┘                                │
│                                                     │
│  总大小 = isa(8) + ivar1 + ivar2 + ... + padding   │
│  总大小必须是16的倍数（对齐）                          │
└─────────────────────────────────────────────────────┘
```

**内存对齐规则：**

| 规则 | 说明 |
|------|------|
| **基本类型对齐** | char=1, short=2, int=4, long=8, pointer=8 |
| **结构体对齐** | 成员最大类型大小的倍数 |
| **对象对齐** | 总大小必须是16的倍数 |
| **数组对齐** | 每个元素按自身规则对齐 |

## 【场景题】
**题目：** 一个包含int和NSString*的对象，内存大小是多少？

**答案：**

```objective-c
@interface Person : NSObject
@property (nonatomic, assign) int age;      // 4字节
@property (nonatomic, copy) NSString *name;  // 8字节
@end

// 内存布局：
// isa(8) + age(4) + padding(4) + name(8) = 24字节
// 24是16的倍数，不需要额外填充
```

## 【代码示例】
```objective-c
// 1. 获取对象内存大小
#import <malloc/malloc.h>

@interface Person : NSObject
@property (nonatomic, assign) int age;
@property (nonatomic, copy) NSString *name;
@end

@implementation Person
@end

Person *p = [[Person alloc] init];
// 获取实际分配的内存大小
size_t size = malloc_size((__bridge const void *)(p));
NSLog(@"Person对象内存大小: %zu", size);  // 24字节

// 2. 获取实例变量偏移量
unsigned int count = 0;
Ivar *ivars = class_copyIvarList([Person class], &count);
for (int i = 0; i < count; i++) {
    Ivar ivar = ivars[i];
    const char *name = ivar_getName(ivar);
    ptrdiff_t offset = ivar_getOffset(ivar);
    NSLog(@"实例变量: %s, 偏移量: %td", name, offset);
}
free(ivars);

// 3. 通过偏移量访问实例变量
// isa在0偏移，age在8偏移，padding在12-15，name在16偏移
int *agePtr = (int *)((char *)p + 8);
NSLog(@"age值: %d", *agePtr);

// 4. NSObject对象大小
NSObject *obj = [[NSObject alloc] init];
size_t objSize = malloc_size((__bridge const void *)(obj));
NSLog(@"NSObject对象内存大小: %zu", objSize);  // 16字节（最小对齐）

// 5. 结构体内存布局
struct Data {
    char c;      // 1字节
    int i;       // 4字节
    double d;    // 8字节
};
// 内存布局: c(1) + padding(3) + i(4) + d(8) = 16字节
NSLog(@"Data结构体大小: %zu", sizeof(struct Data));
```

## 【答题要点】
- 对象内存布局：isa指针 + 实例变量 + 对齐填充
- isa指针在64位系统占8字节，32位占4字节
- 实例变量按声明顺序存储
- 内存对齐：基本类型按自身大小对齐，对象总大小是16的倍数
- malloc_size获取实际分配的内存大小
- ivar_getOffset获取实例变量偏移量
- NSObject空对象占16字节（最小对齐单元）
- 结构体按最大成员类型大小对齐
