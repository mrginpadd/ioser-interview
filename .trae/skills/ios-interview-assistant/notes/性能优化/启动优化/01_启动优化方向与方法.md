# 启动优化

## 【理论题】
**题目：** 请列举iOS App启动优化的方向和具体方法？
**答案：**

**App启动过程：**

```
冷启动时间线：
T0 ────────── T1 ────────── T2 ────────── T3
│             │             │             │
dyld加载    runtime初始化   main()       首屏渲染
(动态库)    (+load)        (didLaunch)  (首屏显示)
```

**优化方向：**

| 阶段 | 优化方向 | 具体方法 | 详解文档 |
|------|---------|---------|---------|
| **dyld阶段** | 减少动态库 | 合并动态库、静态库化、移除无用库 | [02_静态库与动态库详解.md](02_静态库与动态库详解.md) |

## 【场景题】
**题目：** 如何检测启动时间？

**答案：**

```objective-c
// 1. 使用Xcode的Instruments（Time Profiler）
// 2. 手动埋点

// 在main.m开头记录T0
uint64_t startTime = mach_absolute_time();

int main(int argc, char * argv[]) {
    NSString *appDelegateClassName;
    @autoreleasepool {
        appDelegateClassName = NSStringFromClass([AppDelegate class]);
    }
    return UIApplicationMain(argc, argv, nil, appDelegateClassName);
}

// 在AppDelegate中记录T2
- (BOOL)application:(UIApplication *)application 
    didFinishLaunchingWithOptions:(NSDictionary *)launchOptions {
    
    uint64_t endTime = mach_absolute_time();
    uint64_t duration = endTime - startTime;
    
    // 转换为毫秒
    mach_timebase_info_data_t timebase;
    mach_timebase_info(&timebase);
    double ms = (double)duration * timebase.numer / (timebase.denom * 1000000);
    
    NSLog(@"启动耗时：%.2fms", ms);
    
    return YES;
}

// 3. 使用系统API
// T0~T2: -[UIApplication _runWithMainScene:transitionContext:completion:]
// 可以通过Performance API获取
```

## 【代码示例】
```objective-c
// 1. 动态库优化
// - 合并多个动态库为一个
// - 将非必需的动态库改为静态库
// - 使用cocoapods的use_frameworks! :linkage => :static

// 2. +load优化
// 不好的做法：在+load中做耗时操作
@implementation BadClass
+ (void)load {
    // ❌ 耗时操作：加载配置文件、网络请求
    [self loadConfigFromServer];
}
@end

// 好的做法：延迟到+initialize
@implementation GoodClass
+ (void)initialize {
    if (self == [GoodClass class]) {
        // ✅ 懒加载：第一次使用时才初始化
        [self loadConfig];
    }
}
@end

// 3. SDK异步初始化
- (BOOL)application:(UIApplication *)application 
    didFinishLaunchingWithOptions:(NSDictionary *)launchOptions {
    
    // ✅ 异步初始化非必需SDK
    dispatch_async(dispatch_get_global_queue(0, 0), ^{
        [AnalyticsSDK start];
        [CrashSDK start];
        [PushSDK start];
    });
    
    // ✅ 首屏必需的SDK同步初始化
    [CoreSDK initialize];
    
    // ✅ 非首屏VC懒加载
    [self setupLazyLoad];
    
    return YES;
}

- (void)setupLazyLoad {
    // 首屏加载完成后再初始化其他模块
    dispatch_after(dispatch_time(DISPATCH_TIME_NOW, (int64_t)(1.0 * NSEC_PER_SEC)), 
                   dispatch_get_main_queue(), ^{
        [self loadNonCriticalModules];
    });
}

// 4. 二进制重排
// 通过order文件指定符号加载顺序，减少Page Fault
// 工具：dyld_shared_cache_util、FBMemoryProfiler

// 5. 首屏优化
// - 使用占位图（splash screen）
// - 简化首屏视图层级
// - 异步加载图片、数据

// 6. 移除无用代码
// - 使用Xcode的"Remove Unused Code"
// - 使用AppCode的代码分析
// - 移除无用的资源文件

// 7. 延迟初始化示例
// 使用dispatch_once延迟到第一次使用
+ (void)initialize {
    static dispatch_once_t onceToken;
    dispatch_once(&onceToken, ^{
        // 初始化代码
    });
}

// 8. 启动优化检查清单
// - [ ] 动态库数量 < 60
// - [ ] +load方法数量 < 10
// - [ ] didLaunching中无阻塞操作
// - [ ] 首屏资源懒加载
// - [ ] 二进制重排
// - [ ] 无用代码已移除
```

## 【答题要点】
- 启动分为三个阶段：dyld加载、runtime初始化、main()到首屏渲染
- dyld阶段优化：减少动态库、合并动态库、静态库化
- runtime阶段优化：减少+load中的耗时操作，延迟到+initialize
- main()阶段优化：SDK异步初始化、非首屏资源懒加载
- 首屏优化：占位图、简化视图层级、异步加载
- 二进制重排：减少Page Fault，提升启动速度
- 检测方法：Instruments Time Profiler、手动埋点
- 常见误区：在+load中做网络请求、同步加载非必需资源
