# 网络层封装

## 【应用场景】
| 场景 | 说明 |
|------|------|
| **统一请求管理** | 项目中所有网络请求通过统一入口发起 |
| **请求并发控制** | 限制同时发送的请求数量，避免资源耗尽 |
| **统一错误处理** | 所有网络错误、HTTP状态码错误统一处理 |
| **超时配置** | 全局超时和单个请求超时配置 |
| **请求拦截** | 添加公共Header、参数加密等 |
| **响应解析** | 统一解析JSON、处理响应数据 |

## 【实现思路】

```
┌─────────────────────────────────────────────────────┐
│              网络层封装实现思路                        │
│                                                     │
│  1. 单例模式                                          │
│     - 全局唯一实例，统一管理Session和请求队列           │
│                                                     │
│  2. 请求队列管理                                      │
│     - 使用NSOperationQueue限制并发数                   │
│     - 默认4个并发请求，可配置                          │
│                                                     │
│  3. Session配置                                       │
│     - 设置超时时间、缓存策略、默认Header               │
│     - 支持全局配置和单个请求配置                       │
│                                                     │
│  4. 参数处理                                          │
│     - GET：参数拼接到URL                              │
│     - POST：参数放入body（JSON格式）                   │
│                                                     │
│  5. 统一错误处理                                      │
│     - 网络错误：无网络、超时等                         │
│     - HTTP状态码：401、403、500等                     │
│     - 自定义错误提示信息                               │
│                                                     │
│  6. 响应解析                                          │
│     - 自动解析JSON                                    │
│     - 解析失败返回原始字符串                           │
│     - 回调主线程，方便更新UI                          │
│                                                     │
│  7. 请求取消                                          │
│     - 支持单个请求取消                                 │
│     - 支持批量取消所有请求                             │
└─────────────────────────────────────────────────────┘
```

**核心原理：**
- **单例模式**：保证全局唯一的网络请求入口
- **请求队列**：控制并发数，防止请求过多导致性能问题
- **统一错误处理**：将网络错误和业务错误统一封装，便于上层处理
- **线程安全**：使用@synchronized保护共享资源

## 【代码题】
**题目：** 请设计一个简单的网络层封装，支持GET/POST请求，包含请求队列、超时配置、统一错误处理？

**代码示例：**

```objective-c
// HTTPClient.h
#import <Foundation/Foundation.h>

typedef NS_ENUM(NSInteger, HTTPMethod) {
    HTTPMethodGET,
    HTTPMethodPOST
};

typedef void(^HTTPCompletion)(id data, NSError *error);

@interface HTTPClient : NSObject

@property (nonatomic, assign) NSTimeInterval timeoutInterval;  // 默认30秒
@property (nonatomic, assign) NSInteger maxConcurrentRequests; // 默认4

+ (instancetype)sharedClient;

- (void)requestWithMethod:(HTTPMethod)method
                      URL:(NSString *)urlStr
                 parameters:(NSDictionary *)parameters
                completion:(HTTPCompletion)completion;

- (void)cancelAllRequests;

@end

// HTTPClient.m
#import "HTTPClient.h"

@interface HTTPClient () <NSURLSessionDataDelegate>

@property (nonatomic, strong) NSURLSession *session;
@property (nonatomic, strong) NSOperationQueue *requestQueue;
@property (nonatomic, strong) NSMutableArray *activeTasks;

@end

@implementation HTTPClient

+ (instancetype)sharedClient {
    static HTTPClient *client = nil;
    static dispatch_once_t onceToken;
    dispatch_once(&onceToken, ^{
        client = [[HTTPClient alloc] init];
    });
    return client;
}

- (instancetype)init {
    if (self = [super init]) {
        _timeoutInterval = 30;
        _maxConcurrentRequests = 4;
        
        // 创建请求队列，限制并发数
        _requestQueue = [[NSOperationQueue alloc] init];
        _requestQueue.maxConcurrentOperationCount = _maxConcurrentRequests;
        
        // 创建Session
        NSURLSessionConfiguration *config = [NSURLSessionConfiguration defaultSessionConfiguration];
        config.timeoutIntervalForRequest = _timeoutInterval;
        config.timeoutIntervalForResource = 60;
        config.HTTPAdditionalHeaders = @{@"Content-Type": @"application/json",
                                         @"User-Agent": @"HTTPClient/1.0"};
        _session = [NSURLSession sessionWithConfiguration:config
                                                 delegate:self
                                            delegateQueue:_requestQueue];
        
        _activeTasks = [[NSMutableArray alloc] init];
    }
    return self;
}

- (void)requestWithMethod:(HTTPMethod)method
                      URL:(NSString *)urlStr
                 parameters:(NSDictionary *)parameters
                completion:(HTTPCompletion)completion {
    
    NSURL *url = [NSURL URLWithString:urlStr];
    NSMutableURLRequest *request = [NSMutableURLRequest requestWithURL:url];
    request.timeoutInterval = self.timeoutInterval;
    
    // 设置请求方法
    request.HTTPMethod = (method == HTTPMethodGET) ? @"GET" : @"POST";
    
    // 处理参数
    if (parameters) {
        if (method == HTTPMethodGET) {
            // GET：参数拼接到URL
            NSArray *paramPairs = [parameters.allKeys map:^id(NSString *key) {
                return [NSString stringWithFormat:@"%@=%@", key, parameters[key]];
            }];
            NSString *paramStr = [paramPairs componentsJoinedByString:@"&"];
            urlStr = [urlStr stringByAppendingFormat:@"?%@", paramStr];
            request.URL = [NSURL URLWithString:urlStr];
        } else {
            // POST：参数放在body
            NSData *bodyData = [NSJSONSerialization dataWithJSONObject:parameters options:0 error:nil];
            request.HTTPBody = bodyData;
            [request setValue:@"application/json" forHTTPHeaderField:@"Content-Type"];
        }
    }
    
    // 创建任务
    NSURLSessionDataTask *task = [self.session dataTaskWithRequest:request
        completionHandler:^(NSData *data, NSURLResponse *response, NSError *error) {
        
        // 从活跃任务中移除
        @synchronized(self.activeTasks) {
            [self.activeTasks removeObject:task];
        }
        
        dispatch_async(dispatch_get_main_queue(), ^{
            if (error) {
                // 统一错误处理
                NSError *customError = [self handleError:error response:response];
                completion(nil, customError);
                return;
            }
            
            // 解析响应
            id result = [self parseResponse:data response:response];
            completion(result, nil);
        });
    }];
    
    // 添加到活跃任务
    @synchronized(self.activeTasks) {
        [self.activeTasks addObject:task];
    }
    
    // 启动任务
    [task resume];
}

- (NSError *)handleError:(NSError *)error response:(NSURLResponse *)response {
    NSHTTPURLResponse *httpResponse = (NSHTTPURLResponse *)response;
    
    if (httpResponse) {
        NSInteger statusCode = httpResponse.statusCode;
        
        if (statusCode == 401) {
            // 未授权，提示登录
            return [NSError errorWithDomain:@"HTTPClient" 
                                      code:401 
                                  userInfo:@{NSLocalizedDescriptionKey: @"登录已过期，请重新登录"}];
        } else if (statusCode == 403) {
            return [NSError errorWithDomain:@"HTTPClient" 
                                      code:403 
                                  userInfo:@{NSLocalizedDescriptionKey: @"无权限访问"}];
        } else if (statusCode >= 500) {
            return [NSError errorWithDomain:@"HTTPClient" 
                                      code:500 
                                  userInfo:@{NSLocalizedDescriptionKey: @"服务器错误"}];
        }
    }
    
    // 网络错误
    if (error.code == NSURLErrorNotConnectedToInternet) {
        return [NSError errorWithDomain:@"HTTPClient" 
                                  code:-1009 
                              userInfo:@{NSLocalizedDescriptionKey: @"网络连接失败"}];
    }
    
    return error;
}

- (id)parseResponse:(NSData *)data response:(NSURLResponse *)response {
    NSHTTPURLResponse *httpResponse = (NSHTTPURLResponse *)response;
    
    if (httpResponse.statusCode >= 200 && httpResponse.statusCode < 300) {
        NSError *parseError;
        id json = [NSJSONSerialization JSONObjectWithData:data options:0 error:&parseError];
        if (parseError) {
            // 返回原始数据
            return [[NSString alloc] initWithData:data encoding:NSUTF8StringEncoding];
        }
        return json;
    }
    
    return nil;
}

- (void)cancelAllRequests {
    @synchronized(self.activeTasks) {
        for (NSURLSessionTask *task in self.activeTasks) {
            [task cancel];
        }
        [self.activeTasks removeAllObjects];
    }
}

@end

// 使用示例
#import "HTTPClient.h"

// GET请求
[[HTTPClient sharedClient] requestWithMethod:HTTPMethodGET
                                         URL:@"https://api.example.com/users"
                                    parameters:@{@"page": @"1", @"size": @"10"}
                                   completion:^(id data, NSError *error) {
    if (error) {
        NSLog(@"请求失败: %@", error.localizedDescription);
        return;
    }
    NSLog(@"用户列表: %@", data);
}];

// POST请求
[[HTTPClient sharedClient] requestWithMethod:HTTPMethodPOST
                                         URL:@"https://api.example.com/login"
                                    parameters:@{@"username": @"abc", @"password": @"123"}
                                   completion:^(id data, NSError *error) {
    if (error) {
        NSLog(@"登录失败: %@", error.localizedDescription);
        return;
    }
    NSLog(@"登录成功: %@", data);
}];

// 取消所有请求
[[HTTPClient sharedClient] cancelAllRequests];
```

## 【设计要点】
- 单例模式：全局唯一实例，统一管理Session
- 请求队列：NSOperationQueue限制并发数，防止请求过多
- 超时配置：支持全局超时和单个请求超时
- 统一错误处理：封装网络错误、HTTP状态码错误
- 参数处理：GET拼URL，POST放body（JSON格式）
- 线程安全：@synchronized保护activeTasks数组
- 响应解析：自动解析JSON，失败返回原始字符串
- 回调主线程：completion在主线程执行，方便更新UI
- 取消请求：支持批量取消所有请求
