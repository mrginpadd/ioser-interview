# 比重分析

## 核心公式

**比重** = 部分值 ÷ 整体值 × 100%

**部分值** = 整体值 × 比重

**整体值** = 部分值 ÷ 比重

## 常见题型

### 1. 直接求比重
已知部分值和整体值，求比重

### 2. 求部分值
已知整体值和比重，求部分值

### 3. 求整体值
已知部分值和比重，求整体值

### 4. 比重变化分析
比较不同时期比重的变化

## 典型例题

**例题1**：某公司2024年总收入为5000万元，其中研发投入为800万元，问研发投入占总收入的比重是多少？

**解析**：
- 比重 = 800 ÷ 5000 × 100% = 16%

**例题2**：某地区2024年总人口为500万人，其中城镇人口占比为65%，问城镇人口有多少？

**解析**：
- 城镇人口 = 500 × 65% = 325万人

## 答题技巧

1. 比重计算相对简单，注意部分和整体的关系
2. 比重变化分析：
   - 部分增长率 > 整体增长率，比重上升
   - 部分增长率 < 整体增长率，比重下降
3. 可以用十字交叉法快速判断比重变化

## 易错点

- 注意题目问的是"比重"还是"比重变化量"
- 计算比重变化量时需要考虑增长率
- 不要混淆"占"和"是"的区别
