# 行程问题

## 核心公式

**路程** = 速度 × 时间

**速度** = 路程 ÷ 时间

**时间** = 路程 ÷ 速度

## 常见题型

### 1. 相遇问题
- 相向而行
- 相遇时间 = 总路程 ÷ 速度和

### 2. 追及问题
- 同向而行
- 追及时间 = 路程差 ÷ 速度差

### 3. 往返问题
- 两地之间往返
- 注意多次相遇的规律

### 4. 流水行船
- 顺水速度 = 船速 + 水速
- 逆水速度 = 船速 - 水速

## 典型例题

**例题1**：甲乙两人从A、B两地同时出发相向而行，甲速度为60km/h，乙速度为40km/h，A、B两地相距200km，问两人多久相遇？

**解析**：
- 速度和 = 60 + 40 = 100km/h
- 相遇时间 = 200 ÷ 100 = 2小时

**例题2**：一辆汽车以60km/h的速度从甲地出发，另一辆汽车以80km/h的速度从乙地出发追及，已知前车在后方20km处，问后车多久追上前车？

**解析**：
- 速度差 = 80 - 60 = 20km/h
- 追及时间 = 20 ÷ 20 = 1小时

**例题3**：一艘船在静水中的速度为20km/h，水流速度为5km/h，问这艘船顺水航行100km需要多长时间？

**解析**：
- 顺水速度 = 20 + 5 = 25km/h
- 时间 = 100 ÷ 25 = 4小时

## 答题技巧

1. 画线段图帮助理解行程过程
2. 相遇问题用"速度和"，追及问题用"速度差"
3. 注意方向：相向、同向、反向
4. 多次相遇问题：第n次相遇走过的总路程 = (2n-1)×全程

## 易错点

- 混淆相遇和追及公式
- 忽略时间的同时性
- 流水行船中顺水/逆水速度计算错误
- 往返问题中路程计算错误
