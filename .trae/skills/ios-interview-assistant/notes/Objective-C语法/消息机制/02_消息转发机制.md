# 消息转发机制

## 【理论题】
**题目：** 请解释Objective-C消息转发的完整流程？
**答案：**

**消息转发完整流程（5步）：**

```
[obj doSomething] 调用流程：

┌─────────────────────────────────────────────────────┐
│  第1步：快速查找（缓存）                              │
│  在obj的class的方法缓存（cache）中查找，找到直接执行    │
└──────────────────────┬──────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────┐
│  第2步：慢速查找（方法列表）                           │
│  遍历class的方法列表，没找到再逐级找父类，找到加入缓存  │
└──────────────────────┬──────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────┐
│  第3步：动态方法解析                                  │
│  resolveInstanceMethod: / resolveClassMethod:       │
│  可以动态添加方法实现                                │
└──────────────────────┬──────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────┐
│  第4步：备用接收者                                    │
│  forwardingTargetForSelector:                      │
│  找一个备用对象来处理这个消息                         │
└──────────────────────┬──────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────┐
│  第5步：完整消息转发                                  │
│  methodSignatureForSelector: + forwardInvocation:   │
│  封装成NSInvocation，自己决定怎么转发                 │
└──────────────────────┬──────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────┐
│  都没找到 → doesNotRecognizeSelector: → 崩溃！       │
└─────────────────────────────────────────────────────┘
```

**各阶段方法对比：**

| 阶段 | 方法名 | 作用 | 能否返回新对象 |
|------|--------|------|---------------|
| 第3步 | `resolveInstanceMethod:` | 动态添加方法 | 否 |
| 第4步 | `forwardingTargetForSelector:` | 找备用接收者 | 能（返回一个id） |
| 第5步 | `forwardInvocation:` | 完整转发 | 能（自己决定转发给谁） |

## 【场景题】
**题目：** 消息转发有什么实际应用场景？

**答案：**

| 应用场景 | 使用阶段 | 说明 |
|---------|---------|------|
| **动态添加方法** | 第3步 | @dynamic属性、JSPatch热修复 |
| **多代理模式** | 第4步 | 一个对象转发给多个代理处理 |
| **多重代理** | 第5步 | forwardInvocation:实现多播 |
| **Mock/Stub** | 第5步 | 单元测试中模拟对象行为 |
| **防崩溃** | 第5步 | 捕获未知方法，避免崩溃 |

## 【代码示例】
```objective-c
// 1. 动态方法解析（第3步）
@interface Person : NSObject
- (void)run;  // 只声明，不实现
@end

@implementation Person

+ (BOOL)resolveInstanceMethod:(SEL)sel {
    if (sel == @selector(run)) {
        // 动态添加方法实现
        class_addMethod(self, sel, (IMP)runIMP, "v@:");
        return YES;
    }
    return [super resolveInstanceMethod:sel];
}

void runIMP(id self, SEL _cmd) {
    NSLog(@"Person在跑步");
}

@end

// 2. 备用接收者（第4步）
@interface Dog : NSObject
- (void)bark;
@end
@implementation Dog
- (void)bark { NSLog(@"汪汪汪！"); }
@end

@interface Person : NSObject
@property (strong, nonatomic) Dog *dog;
@end

@implementation Person

- (id)forwardingTargetForSelector:(SEL)aSelector {
    if (aSelector == @selector(bark)) {
        return self.dog;  // 让dog来处理bark消息
    }
    return [super forwardingTargetForSelector:aSelector];
}

@end

// 3. 完整消息转发（第5步）
- (NSMethodSignature *)methodSignatureForSelector:(SEL)aSelector {
    // 返回方法签名
    return [NSMethodSignature signatureWithObjCTypes:"v@:@"];
}

- (void)forwardInvocation:(NSInvocation *)anInvocation {
    // 自己决定怎么处理这个消息
    if ([self.dog respondsToSelector:anInvocation.selector]) {
        [anInvocation invokeWithTarget:self.dog];
    } else {
        [self doesNotRecognizeSelector:anInvocation.selector];
    }
}
```

## 【答题要点】
- 消息转发共5步：快速查找 → 慢速查找 → 动态方法解析 → 备用接收者 → 完整消息转发
- 前2步是方法查找，后3步是消息转发
- 动态方法解析用resolveInstanceMethod:
- 备用接收者用forwardingTargetForSelector:
- 完整消息转发用methodSignatureForSelector: + forwardInvocation:
- 都没找到会调用doesNotRecognizeSelector:导致崩溃
- 应用：动态添加方法、多代理、防崩溃、热修复
